# 桌面基础组件

组件集中在 `internal/desktop/components`。连接、文件、服务器状态等页面已接入这些组件。继续使用固定版本的 MyGo，保留它的原生焦点、键盘、可访问性、虚拟列表与弹窗能力。

## 使用约定

- 普通操作用 `Button`；主操作用 `PrimaryButton` 或 `ButtonOptions{Variant: Primary}`；危险操作用 `Variant: Destructive`。不要在业务页面覆盖按钮背景色来表示危险状态，这会破坏悬停和按下反馈。
- `ButtonOptions{Busy: true}` 同时显示进度和禁止重复触发；`Disabled` 表示暂不可用。常规按钮默认高度 32，表单可选 `FormHeight`；解锁等特殊布局可以显式设置高度。
- `IconButton` 必须提供动作名称，供提示和辅助技术使用。`ActionGroup` 排列相关操作，`ButtonGroup` 使用 MyGo Toolbar 的方向键导航与窄宽度溢出菜单。
- 每个列表、表格、目录树保存独立的 `ui.ListState`。提供稳定且唯一的 key，避免使用排序后的行号作身份。
- `Table` 使用 MyGo 的列标题、排序箭头、列宽调整与列顺序。可排序列必须提供稳定的 `ID`、`Sortable: true`，并设置 `state.Sort`。业务层按该顺序整理数据，然后传给组件；数值、时长和未知值的比较规则留在业务层。表头更改排序后，组件请求下一帧并滚到顶部。不要在单个页面重写排序箭头或刷新处理。
- `VirtualTree` 接收已缓存的扁平索引，通过访问函数读取可见行。它不遍历目录、不读取磁盘或服务器；索引仅在目录数据、展开状态或当前位置改变时重建。`OnSelect` 导航，`OnToggle` 展开 / 折叠，`Decorate` 接入上下文菜单和拖放。
- `FileList` 接收与 SSH 无关的 `FileEntry`。`ID` 保留实际文件名，`Name` 是经过可见字符处理的显示文字；选中、删除、传输仍绑定实际身份。`Decorate` 接入原有点击、多选、双击、菜单和拖放，操作时仍由业务层保存不可变目标快照。文件列目前保留原有目录优先顺序，不隐式改变文件操作的索引语义。
- 文件目录使用 `DirectoryTree`，普通树继续使用 `VirtualTree`；二者复用同一套虚拟行和键盘交互。`DirectoryTree` 与 `FileList` 共用被动的 `FileName`，统一 16 DIP SVG 图标、26 DIP 行高、6 DIP 图文间距；展开箭头单独占位，空目录仍显示文件夹，避免无箭头的行被弹性占位推向右侧。选中使用明暗主题下的浅色背景；隐藏项文字稍淡，大小列右对齐。图标仅按显示名称区分代码、图片、压缩包和普通文件，不读取文件内容。只改图标 / 名称 / 密度时修改组件，路径和权限继续由业务层处理。
- `Dialog` 负责布局及 MyGo 的焦点约束与 Escape。校验、确认、取消后的清理、敏感数据生命周期和授权检查均由调用者负责。组件不会隐式批准操作、校验或自动关闭窗口。
- `DialogOptions.Height` 可限制长表单高度，使内容滚动而标题和底部按钮始终可见；宽高自动限制在窗口内。`Close` 提供标题栏关闭动作，`CloseDisabled` 禁用该按钮。Escape / 遮罩关闭仍由调用方处理，原子保存阶段必须保持编辑器及凭据生命周期。新建、编辑与首次主机身份确认复用同一个 Dialog，保留原终端工作区和标签。
- `PermissionMatrix` 只维护九个布尔值及八进制预览，不读取属性或发起请求。`EditableChoice` 复用原生 `ComboboxBase` 的焦点、弹层与键盘导航，保留手输数字；离开输入框不强制替换为既有选项。数据加载、账户名称解析、权限校验、目标快照和保存均由业务层负责。
- `SplitPercent` / `SplitVerticalPercent` 使用 `SplitLimits` 限制范围；只有未初始化或非有限值才使用默认比例。拖过边界时保留边界值，反向移动立即响应，不恢复默认位置。业务层根据工作区宽高提供边界，窗口缩放后重新适配。不得在每帧渲染中把超界比例重置为默认值。

新增同类功能应复用这里的组件；修改共同行为时先改组件，再检查使用页面。不要把凭据、SSH 客户端或权限判断放进组件包。

工具面板栏参考 [Chrome DevTools 的面板与抽屉结构](https://developer.chrome.com/docs/devtools/customize)。`PanelBar` 接收稳定 ID 与标题，复用 MyGo `TabsBase` 保留方向键和可访问性，支持不连续的已保存 ID。图标动作使用 `SVGButton`，不依赖字体字符的形状。传输作为全局任务入口，由业务层组合原生 Popover 与共享虚拟列表；它不改变面板标签或原有分栏，任务进度不会自动打开浮层。

Docker 的常用查看继续留在工具区：`containerDetailsView` 组合共享按钮、原生 Tabs / Select 和虚拟列表，容器日志与后台任务输出共用 `dockerLogList`。日志字节流由与 UI 分离的 `internal/dockerlog.Buffer` 限制大小、处理跨块控制序列；只有版本或查询变化时重建筛选结果，普通帧不复制整个日志缓存。每个日志视图持有独立列表、搜索、滚动跟随和通知合并状态，停靠 / 独立窗口迁移时重绑列表运行时，保留数据和筛选。

`docker_dialog.go` 管日志检查与容器终端入口，`compose_work.go` 管更新预览、后台任务及结果；更新确认和任务详情复用共享 Dialog。`serverops/docker_work.go` 只构造经过校验的目标及固定动作，`broker/docker_work.go` 执行阶段、复核模型并转发结果，`sshconn/stream.go` 提供有取消生命周期的实时通道。GUI 和 CLI 使用同一组类型化操作及审批证明，没有新增直连 SSH 路径。任务中心在有服务器操作时复用原传输入口，进度变化不自动打开浮层或改变标签。

顶栏左端的共享侧栏开关根据当前页面分别控制连接列表、授权分类和设置分类的完整 / 图标模式；三个展开状态独立保存。收窄后保留 48 DIP 窄栏中的可点击头像或分类图标。授权分类从顶部移入左侧，右侧请求列表 / 窄屏选择器仍独立可用。工具开关只在工作台显示，任务和锁定为全局操作；主窗口局部工具栏不再复制这些动作。`PanelBarOptions.Leading` 仍作为共享组件的可选插槽，文件工具栏不使用它复制应用导航。每个文件窗口的菜单管理拆分、本机来源与排列，文件数据操作留在文件 / 目录右键菜单。

应用顶栏、连接操作栏、终端标签栏与工具栏统一为 36 DIP 高度和 6 DIP 水平留白，顶栏与终端 / 工具栏使用 `HeaderBar`。共享侧栏开关固定在顶栏最左侧，三页切换及侧栏收起 / 恢复都保持相同坐标；导航、任务、工作台工具开关和锁定仍处于原有一行。侧栏、锁定与页面限定按钮在构造前设置稳定 Key，避免切页时复用兄弟节点的焦点或按压状态。搜索框与内容区的内边距独立设置。

标题和标签文字共用 `HeaderLabel`，对字形绘制位置向上校正 1 DIP，使可见文字与 SVG 图标视觉居中；不改变行高、按钮范围或焦点。标题栏新增连接按钮使用 SVG 加号，避免字体字形留白造成偏移。

应用级导航与局部菜单分开：顶栏直接切换工作台、授权中心和设置，三个页面独立占据完整内容区，只有工作台挂载连接侧栏与终端 / 工具分栏。切页保留会话、文件固定目标、目录、分栏和展开状态；主内容按页面设置稳定身份，避免不同页面共享控件状态。全局锁定为直接图标按钮，恢复默认布局位于设置的工作区分类；不再保留空泛的应用弹层。导航和锁定继续经过 `runMenu` 的草稿 / 未保存检查，原生系统菜单和快捷键保留。终端标签及分组动作属于终端栏，文件操作与文件窗口布局属于各自的上下文菜单。

`settings.go` 用 `settingsCategories` 集中登记分类 ID、标题与渲染函数，左侧使用共享 `NavigationSidebar` / `NavigationIcon`，两种宽度均以方向键移动焦点、Enter / Space 激活分类，右侧按分类独立滚动并限制可读宽度。分类栏可由全局左上按钮缩为图标栏，窄栏沿用相同分类 ID 与选择逻辑；内容滚动区在构造前设置稳定 Key，折叠前后保留分类、滚动和输入状态。当前仅展示已实现的工作区、安全与解锁两类；新增偏好按真实功能归类，避免提前展示不可用选项。布局偏好调用既有操作但保持设置页与当前焦点；离开安全分类清除主密码输入并取消待完成验证。系统验证的口令要求、可用性、取消和错误反馈沿用既有安全流程。

标准工作区为左侧连接列表、右侧上终端 / 下工具。应用顶栏独立控制侧栏和工具显示；终端栏只管理标签及终端分组，工具栏只管理工具选项卡与自身停靠 / 放大 / 收起。布局帧快照继续覆盖侧栏、工具显示、停靠和放大状态，焦点请求只在新布局建立后消费，保留终端和编辑器输入。

`PanelLayoutMenu` 是共享的停靠选择组件，点击工具面板右上角 `⋮` 打开。参考 Chrome 的结构，顶行左侧为“停靠侧”，右侧依次为独立窗口 / 底部 / 右侧的小图标按钮，选中位置高亮；不再使用大卡片或重复文字。下方分隔线后排列放大 / 恢复、收起面板，右端显示当前平台的收起快捷键。独立窗口使用系统窗口缩放，不显示面板放大操作。标题栏和菜单复用简洁的分区图标。

左右键在停靠图标间移动，上下键遍历菜单行，Enter / Space 执行；Esc 关闭并把焦点交还入口，点击外部则保留被点击内容的焦点。组件返回动作，业务层统一调整停靠、显示和放大状态，保留终端、文件目标和输入焦点；邻近 `×` 仍独立收起面板。右侧分栏在窄窗口中限制最小可用宽度，避免菜单与关闭按钮被裁切。

`tool_window.go` 管独立原生窗口的生命周期，面板内容仍由 `fileArea` 复用，不复制数据或 SSH 会话。新建和销毁延后到当前渲染帧之外；窗口关闭序号使已取消的创建和过期的关闭回调失效。锁定、退出关闭附属窗口；启动不恢复可见独立窗口，只有用户主动操作才显示。

迁移时重新绑定列表 / 网格的窗口内布局状态，保留选择、列布局、数据缓存和近似滚动位置；资源视口滚动状态仍随会话保存。后台 UI 更新同时通知两个窗口，共享目标或布局变化才触发对端重绘，终端的普通输出帧不会持续重绘工具窗口。确认框、命令表单及传输浮层分别保留所属窗口，避免重复显示；原生关闭快捷键按操作来源处理，不会误关闭 SSH 标签。

资源概览只显示 CPU、内存、网络、磁盘四张卡片与系统摘要；核心、网卡、TCP、块设备及挂载点在点击卡片后的详情页查看，容器保留在 Docker 页。卡片最小宽度为 180 DIP、间距 8 DIP，按实际可用宽度排列 1～4 列，容不下完整一列时自动换行。视口低于 260 DIP 时使用 64 DIP 指标卡，保留标题、当前值、关键说明及详情入口；视口变高后恢复 106 DIP 迷你趋势卡。资源概览、详情和系统信息在右侧预留 14 DIP 滚动条空间，网格按扣除留白后的宽度分列。布局完成后测量视口，尺寸变化时请求更新，静止后不会持续刷新。两种密度共用数据与详情流程，不改变工具面板或终端大小，数值不再重复 CPU / 内存标题。

节间距为 8 DIP；共享资源表面使用 9 DIP 内边距与 7 DIP 内容间距。四个以内的虚拟网卡按内容自然排布，不使用固定行高或内层滚动条；更多网卡使用高度受限的原生虚拟列表，行高随宽度和实际内容测量。

`ResourceLayout` 在共享网格上按卡片内容指定最小可读宽度和列数上限：挂载点为 360 DIP / 三列，容器为 400 DIP / 两列。`Grid` 使用 `ResourceColumns` / `ResourceGrid`，列数还受实际卡片数量限制：单张撑满整行，两张均分，空间达到两张最小宽度与间距后才分列，避免为不存在的卡片预留整列。每张卡片放在独立单元中，使 `Surface` 的百分比宽度相对单元解析；集合多行时末行保持列宽。`CardGrid` 对原生虚拟网格施加相同规则，保留键盘、选择及滚动；同时参考当前面板宽度与上一帧实测宽度，避免反向缩放后停留在旧列数。Compose 项目和项目内的容器分别使用独立的原生虚拟网格，一张项目卡汇总所属容器；单项目撑满一行，项目和容器最多两列。主窗口最小宽度为 560 DIP；宽度不足以并排容纳终端和右侧工具时，当前帧改到底部布局，保存的停靠方向不变，宽度恢复后回到右侧。工具栏与资源详情也按相同的实际面板宽度换行。

文件内部布局由业务层 `file_layout.go` 的分栏树管理，叶节点持有独立浏览器，分支只持有方向与比例；显示继续复用 MyGo 原生分栏、文件树和文件列表。左右 / 上下 / 网格排列只重组节点，不重建已有浏览器。新拆分窗口复制已加载目录和位置，选择、表格、树展开状态及读取任务独立；默认固定到拆分时的目标，可手动改成跟随当前终端。关闭窗口取消其读取，锁定取消所有窗口及缓存窗口读取。文件栏 `＋` 管整体排列，各窗口的 `⋮` 管局部拆分与关闭；最多 8 个，默认 1 个。目录树默认宽度 180 DIP，并随窄窗口缩小。来源选择位于树上方，路径、刷新与窗口菜单位于文件列表上方，两列头部共用 36 DIP 高度，并与内容使用同一条原生分隔线；路径文字与“名称”表头对齐。窄窗仍保留单排头部；来源长名称截断并提供完整提示，展开选择器后显示完整选项。按窗口宽度收紧目录树时请求完整新一帧，避免点击区域沿用旧布局。独立窗口和放大面板显示修改时间；底部紧凑面板保留名称和大小。多窗口传输继续捕获具体来源与目标，有多个目标时菜单要求明确选择。

`terminal_layout.go` 管最多两个左右排列的终端组，每组独立持有标签顺序、当前会话和编辑标签选择。`terminal_group_view.go` 用同一套 MyGo 标签、拖放及 Ghostty 渲染各组，不复制 PTY 或输出缓冲区，不再另设总标签栏或重复的分屏标题。拖放支持组内排序、跨组移动及右侧创建分组；结构改变在当前渲染结束后提交，避免同一 PTY 在一帧中挂到两个父节点。空组自动收回，合并保留所有连接、记录和编辑文档。

顶部“终端分栏”图标提供新建到另一组、移动当前标签与合并，标签右键提供移到另一组。新建仅在 broker 身份验证和独立 PTY 创建成功后提交，失败保留原布局；连接期间切换焦点时，完成结果留作后台标签。新连接保留发起时的目标组；关闭只断开所选终端；同机多会话名称加序号，重连保留指定分组、位置与标签身份。窄组精简动作区，其他入口仍可通过系统菜单使用。

工具面板位于终端组之外，始终一套。当前输入焦点决定活动会话、服务器状态、常用命令目标和跟随文件窗口；手动固定的文件窗口不变。原生输入焦点只交给活动终端，布局帧快照也包含分组结构，避免新旧布局交替时将输入发给另一会话。编辑器作为所在组的独立标签，拖动到另一组保留文档，另一组的终端继续可见。

## 离线验收

文件属性由 `file_properties.go` 管理单一弹窗及读取 / 保存上下文，主窗口和独立工具窗共用状态，停靠迁移保留未提交值。打开时固定来源服务器和路径；切换终端不会改变目标，关闭 / 锁定使旧回调失效。目录树和列表共用修改菜单，`file_mutations.go` 同步同服务器各浏览器的目录缓存；目录移动或删除后取消旧读取、清除旧子树并修正当前位置。

`internal/fileattrs` 管基础权限、名称 / 数字账户解析和元数据校验；SFTP 和本机都在打开的文件句柄上修改，保存前比较已核对的属性，失败时尽量返回实际结果。所属用户 / 组先保存，随后修改权限位；不恢复系统在 chown 时清除的 set-ID 标志。账户清单只从固定的公开账户文件提取名称和 ID，并限制大小、行长与数量；不传回密码、哈希或组成员字段。远程操作不拼接 Shell 命令，不自动 sudo。普通文件及目录需能由当前账户打开属性句柄；系统拒绝读取或修改时保留错误，可重新读取或取消。远端名称清单不覆盖所有 NSS 来源，未列出的账户可用数字 ID；Windows 本机不支持 Unix 所有权。

`file-attributes` 的审批证明绑定路径、预期属性、修改标志、权限和 UID/GID，UID/GID 为 0 仍作为显式修改处理；只读子授权允许查看属性，拒绝修改。SFTP 元数据比较不能证明服务端 inode 身份，支持范围内的并发变化会拒绝保存；不把它当作跨系统的原子事务，部分修改完成后不回滚。

`components/components_test.go` 覆盖按钮鼠标 / 键盘、明暗主题下悬停与按下反馈、禁用与忙碌、按钮组方向键、弹窗焦点与校验、数值排序和稳定选择、十万项虚拟目录树与文件列表。现有业务测试继续覆盖多选、拖放、路径快照、连接保存、加密和授权边界。

无需打开窗口即可测试：

```sh

go test -race -tags terminal_integration ./... -timeout 300s
```

## 服务器状态区域的布局规则

`status_layout.go` 集中保存各类卡片的宽度与列数规则。列数同时受可用宽度、最小可读宽度、实际卡片数量及该类卡片的列数上限约束。单张使用全宽，不为空卡片保留整列；`ResourceLayout.CellWidth` 供卡片内部决定指标密度。

| 区域 | 最小卡片宽度 / 最多列数 | 内容适配 |
|---|---|---|
| 操作系统、硬件 | 360 DIP / 两列 | 窄窗上下排列；长型号、内核、CPU 名称换行 |
| Docker 容器、Compose 项目内的容器 | 400 DIP / 两列 | 保留虚拟化、选择、排序与操作；每个项目按完整容器数量计算列数 |
| 容器详情、端口映射 | 360 DIP / 两列 | 每条映射单独显示；长 IPv6、端口范围、容器 ID 可换行、选择和复制 |
| 物理、虚拟网卡 | 420 DIP / 两列 | 名称、地址与指标分开；按卡片自身宽度排两列或四列指标；四张以内自然高度，更多虚拟网卡按网格行虚拟化，视口最高 320 DIP |
| 块设备 I/O | 360 DIP / 两列 | 吞吐量、读写 IOPS、忙碌率；缺采样显示未知 |
| 文件系统 | 360 DIP / 三列 | 单挂载点撑满；长设备路径省略并提供完整提示 |
| 逻辑核心仪表 | 160 DIP / 四列 | 按实际核心数量分列，单核心不保留空列，最多显示 256 核 |
| CPU / 内存 / 网络 / 磁盘摘要 | 四 / 二 / 一列 | 始终四项，浅面板优先让当前值同时可见，面板增高后恢复迷你趋势 |
| TCP 汇总、趋势与明细数值 | 单块占满 | 指标自行换行；图表保留连续时间轴 |
| 进程、自启服务、容器列表、镜像列表 | 表格占满 | 保留列头排序；窄窗横向滚动到末列，工具栏保持可用 |
| Docker 日志 | 内容占满 | 窄窗工具栏自然换行；日志仍为有上限的虚拟列表 |

现有端口信息来自 Docker 的容器端口映射；尚无主机监听端口采集与独立清单。GPU 数据也尚未接入，这两项不算本轮已适配页面。

Compose 聚合由 `internal/monitor/compose_projects.go` 处理：标签识别、状态归类、异常优先排序、服务去重及资源样本覆盖率与布局无关。`internal/desktop/compose_projects.go` 复用 `ResourceLayout.CardGrid`、按钮、指标和现有容器卡；项目总览与容器详情使用独立滚动状态，选择绑定 Docker 实例和 socket。筛选不修改汇总或更新目标；配置来源校验共用 `composeUpdateIssue`，确认框仍捕获固定服务器、项目与服务。工具窗停靠迁移重绑定两套网格，保留项目选择。

项目生命周期菜单由 `compose_lifecycle.go` 管理，总览右键和详情标题栏复用同一菜单。确认框捕获服务器、项目、服务及完整容器身份；`serverops.ComposeLifecycle` 生成带 socket / 实例 / 成员 / 来源校验的白名单操作，复用共享 owner / exec 授权及原服务器反馈，关闭和切换标签不会把目标改到新会话。普通服务器操作仍等待 40 秒，项目生命周期单独等待最多 6 分钟；不改变终端布局。


## 可见文案与可点击列表项

页面标题、字段标签和布局已经表达的信息，不再用副标题、段落或常驻时间戳重复说明。正常状态简短展示；采样时间、技术口径和静态帮助按需查看。错误、异常、真实操作目标、授权范围、配对核对和变更后果仍直接可见。图标的 Tooltip、可访问性 Label 和键盘语义保留。

多行请求卡使用共享 `ListItem(c, key, label, selected)`，构造时传入稳定 key，在读取悬停 / 按下状态前绑定，不在返回后链式改 key；按内容测量高度并保留原生按钮的焦点和激活语义；普通 `Button` 继续使用固定控件高度。列表项首行显示申请方，次行显示操作与服务器，不把三行内容塞进普通按钮，也不为个别卡片修改所有按钮高度。

文件来源显示实际服务器名，跟随状态用共享图标和提示表达。Compose 计划与当前镜像相同时收起重复列表；存在差异时直接展示实际计划，保留所选服务与重建中断提醒。


`NavigationSidebar` 在完整宽度与 48 DIP 之间只改尺寸，共用滚动区、焦点组及稳定父身份；`NavigationItem` 的行高 40 DIP、间距 4 DIP、左侧图标槽 36 DIP、分类圆形图标底 28 DIP 保持不变；文字额外留 6 DIP 起始间距，类别侧栏上下留白 10 DIP。展开仅增加右侧文字；展开模式的选中 / 焦点描边叠加绘制，窄栏通过原图颜色变化反馈，不挤动图标。`NavigationRail` / `RailItem` / `RailIcon` 作为紧凑包装保留。

工作台两种宽度共用同一虚拟列表、筛选条件、分组展开状态与滚动位置；顶部操作 / 搜索区域固定 36 DIP；展开的搜索框高 28 DIP、上下各留 4 DIP，分组行固定 20 DIP，连接头像始终显示。完整侧栏和窄栏复用菜单，单击与键盘只选择，每次双击都新建独立终端；登录期间的多次双击按次排队，取消或失败清除队列。终端标签切换只更新终端及跟随工具，保留侧栏选择与滚动位置。`SidebarSplit` 保持左右内容的父节点及身份不变，只调整宽度；收窄时拖动柄禁用并穿透指针，展开时拖动柄在最后一层捕获分隔线两侧操作。

`ConnectionAvatar` 用连接 ID 的摘要生成固定颜色和对称图案，使用本地 SVG、最多 512 项缓存，不读取连接凭据或请求网络。分组索引在连接资料变化时重建，等值刷新与普通帧复用索引；锁定清空索引、来源快照及列表回调持有的连接资料。收窄工作台仍占 48 DIP，停靠判定和资源卡片断点按实际剩余内容宽度计算。


新建、搜索的圆形底和 SSH 连接头像的可见直径统一使用 `NavigationCircleSize`（28 DIP）。头像直接填满这个圆，不另加外圈；操作图标内部的线条仍为 `NavigationGlyphSize`（16 DIP）。36 DIP 图标槽和中心位置不变，展开与收窄保持一致。


窄栏不绘制附加圈、描边或悬停覆盖层：点击区域保持 36×40 DIP（顶部按钮高 36 DIP），父项背景透明；选中、悬停、按下与键盘焦点仅轻微调整原图透明度，线图标焦点继续使用强调色。展开时保留整行反馈，头像与条目位置不变。

工作台、授权中心和设置仅共用一个 `sidebarHidden` 状态。顶栏按钮、设置开关、搜索展开与恢复布局都使用它；切换主页面不重置状态，各页内容选择仍独立。布局继续读取 v1/v2、写 v2，只保存 `sidebarHidden`；旧分页字段被忽略，不覆盖共享状态。
