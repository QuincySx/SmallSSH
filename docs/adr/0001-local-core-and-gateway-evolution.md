# 先交付本机安全核心，保留远程网关的独立认证适配

用户选择 B：安全核心独立于图形工作台运行，现有 App 功能保留，同时要求未来可演进为 D 的远程访问网关。0.1 首先交付本机模式；协议、权限决策、受控执行、审计和后台任务不依赖窗口或具体传输，本机进程验证和远程主体认证通过不同适配进入核心，不提前开放远程监听。

单进程退到菜单栏只能改善窗口关闭体验，无法解决工作台崩溃 / 升级与核心耦合，因此不作为 B 的完成标准。直接建设远程网关会同时引入多用户、设备身份和网络攻击面，超出当前需求；这些能力按接口和演进计划保留，不用本机 PID 或自报客户端角色充当远程信任根。现有凭据文件、单次所有者证明和客户端活连接约束要逐项迁移并保留回归证据，不能通过隐藏旧功能或放宽授权降低拆分难度。
