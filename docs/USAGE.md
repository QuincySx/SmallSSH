# 使用说明

SmallSSH 将终端、SFTP、远程桌面和服务器管理放在同一个工作区。[构建与安装](DEVELOPMENT.md) · [CLI 与 SDK](CLI.md) · [安全与边界](SECURITY.md)

## 首次使用

1. 打开 App 并创建本机保险库。已有保险库时输入主密码解锁，macOS 可在「设置 → 安全与解锁」配置系统验证。
2. 从左上角「＋」新建连接，填写地址、端口、用户名和登录方式。可以设定分组、备注、默认线路和终端偏好。点「保存」仅加密写入本机配置。目标 DNS 查询和网络拨号在实际连接时发生。
3. 双击已保存的服务器或选中后按 Enter，打开新终端。首次连接时按本次线路核对主机指纹，选择「信任并连接」后才会向目标认证。指纹变化时，在连接菜单明确重新核对。
4. 「登录方式 → 已有私钥」支持选择 OpenSSH / PEM 文件，也可以复制含首尾标记的完整文本后点「粘贴私钥」。加密的私钥需要填写口令。保存时将凭据加密写入本机保险库。编辑连接时需要先选「更换登录凭据」才能换私钥。

## 工作区与终端

- 在左侧搜索、排序或分组服务器。拖动可调整分组顺序、组内顺序和所属分组。
- 顶部标签切换终端、VNC 和已打开的工具。拖到窗格四边可分栏，在「设置 → 工作区」切换画布或标签聚合。界面缩放和上一 / 下一个标签的快捷键见「视图」菜单。
- 文件、状态和命令工具可停靠、打开为标签或移到独立工具窗。顶栏任务入口显示传输和服务器操作，可查看进度、暂停、续传或清理记录。已完成的任务默认在「历史」，可单条移除或清空。
- 终端按连接使用 UTF-8、GB18030 或 GBK，也支持自动检测及退格设置。远端 Shell 的方向键历史和 Ctrl+R 沿用远端会话。
- 命令模板可包含参数。发送前核对渲染出的命令和目标终端。「填入」留给用户核对，「执行」发送到选中的终端。参数历史按服务器和命令版本隔离，可从设置关闭或清空。
- 「设置 → 工作区」提供中英文及跟随系统选项。关闭窗口是退出还是驻留，可在「运行与后台」选择。退出应用或锁定会结束本机活动授权和连接。

## 文件与传输

文件管理显示目录树、路径、文件列表与选择统计。可以跟随当前终端，也可以为每个窗格选择本机或已保存的服务器。更多菜单支持拆分、添加本机窗格及调整排列。

- 点目录树、双击目录或在地址栏按 Enter 导航。右键可执行新建、重命名、属性、权限和删除。目录删除只针对空目录。
- 远程窗格的「上传文件」打开系统文件选择器，可多选并上传到当前目录。也可以从 Finder 或资源管理器拖入文件。拖到某个文件夹会上传到该文件夹，拖到列表空白处则上传到当前目录。
- 点击名称、大小或修改时间表头排序，再点切换升降序。窄窗下可在「…」菜单按修改时间排序。
- 上传遇到同名普通文件时，可选择「跳过」或「覆盖」。覆盖成功后保留旧副本，可在任务详情提示中查看位置。
- 在同一服务器或本机内，把文件拖到列表里的文件夹、目录树节点或工具栏的「上一级」可以移动。支持多选，同名冲突的文件留在原处。
- 本机与服务器窗格之间可用右键或拖放传输。目录下载保留目录层级和空目录，经任务中心查看扫描与进度。下载会保留本机已有目标。有同名文件、符号链接或不支持的文件时，处理冲突后再重试。
- 文本文件双击打开独立编辑窗，支持 4 MiB 以内且无 NUL 的 UTF-8 文本。覆盖保存核对远端版本并保留旧副本，关闭会检查未保存修改。
- 清除任务历史会清理对应记录及任务元数据，已下载的文件保留。连接或保险库锁定中断后，可在解锁后按任务状态继续。

## 线路和端口转发

- 「设置 → 加速与代理」管理共享线路，连接可引用已保存的代理或选用 SSH 跳板机。线路修改在下次连接生效。连接设置可比较握手耗时。启用保活后，程序会定期探测连接，超过设定阈值无响应就断开。关闭保活时停止发送探测，保留设定值。
- 代理支持 HTTP / HTTPS CONNECT 与 SOCKS5。也可粘贴 Shadowsocks、Snell、VLESS / REALITY、AnyTLS、Hysteria 2 的分享链接，或导入单节点、节点数组及含 `outbounds` 的 JSON。Snell v5 使用 TCP 兼容模式，v6 支持 `mode` 和 `reuse`。
- 「终端连接」右键菜单可用已连接的 SSH 中继或运行中的 SOCKS5 入口。还可以选「新建 SSH 中转」并点一台已保存的服务器，SmallSSH 按需连通中转和目标，只打开目标终端。菜单分隔线区分默认选项、现用通道和新建或已保存线路。一次性选择不改服务器默认线路。
- 右上角「端口转发」打开列表，点「新建服务」后选一张用途图。服务器、地址和端口直接在图上编辑。点连线上的「＋」可选线路，点中转旁的「×」恢复本次直连。选「本机已有 SOCKS5」后填写代理地址。访问远端服务时可勾选「启动后打开网页」。启动成功后可复制实际入口或停止。

| 隧道 | 用法 |
| --- | --- |
| 本地转发 | 从本机指定端口经 SSH 访问远端固定服务 |
| 远程转发 | 从 SSH 服务器指定端口访问本机侧固定服务 |
| 动态 SOCKS5 | 本机提供代理入口，由应用指定各次连接的 TCP 目标 |

监听使用回环地址，远端转发的实际绑定还受 SSH 服务端配置约束。停止服务会关闭监听和相应转发流量。命令行示例见 [CLI](CLI.md#连接选项硬件枚举与隧道)。

### PKCS#11 硬件密钥

编辑连接时选择硬件认证，读取可信模块提供的令牌及公钥，选择身份并按设备要求输入 PIN。FIDO2 和 `sk-` 类型使用 SSH Agent。设备、模块和系统的组合以实机验收为准。

## 服务器状态与 Docker

「服务器状态」随当前终端展示 CPU、内存、网络和磁盘，可切换进程、服务、系统信息、监听端口及 Docker。趋势时间范围位于状态栏右侧更多菜单。缺失或过期采样会标明，端口页显示监听和已见连接。

进程、systemd 服务与容器操作先核对目标。容器详情可查看、搜索和跟随日志，或打开容器终端。Compose 更新先选服务并确认计划，拉取后再次核对配置，再重建选中的服务。进度和失败阶段显示在「任务中心 → 服务器操作」。CLI 参数见 [Docker 与 Compose](CLI.md#docker-与-compose)。

服务器右键「备注」保留手写内容。点「检测服务和域名」才采集自动概览。服务分类在本地匹配，独立规则见 [catalog.json](../internal/servernotes/catalog.json)。自定义服务保留其名称。系统服务、端口和扫描范围在检测详情展开。

## VNC 远程桌面

服务器右键选择「VNC 远程桌面」，填写主机与端口，默认 5900。直连使用 VNC 目标地址。经 SSH 通道时，目标地址由 SSH 服务器访问，若 VNC 在该服务器本机回环监听，可填 `127.0.0.1`。

连接在工作区标签打开，认证成功后可保存 VNC 密码。右侧工具栏提供全屏、重连、只读和键盘操作，空间不足时在「⋯」中查看剩余操作。通过两个剪贴板按钮复制远端文本或粘贴本机文本。关闭标签、锁定或退出结束连接。

## 授权中心与 SSH 密钥

在「设置 → 授权中心」核对待确认操作、调整当前授权或查审计。受控会话可调整闲置时间、实时切换中风险文件操作确认和立即撤销。审计支持筛选、查看关联项目与导出匹配的 JSONL 或 CSV。

macOS 的「登录方式 → SmallSSH 密钥」可以读取现有密钥，或点「新建密钥」生成 Secure Enclave 密钥。选中后点「复制公钥」，把它添加到服务器。也可以在「设置 → SSH 密钥」集中管理。外部 OpenSSH 可用设置页给出的 `IdentityAgent` 路径。密钥限时许可作用于整把密钥的后续签名。两类授权的范围见 [安全与边界](SECURITY.md#服务器操作与密钥使用授权)。

「硬件密钥」在 macOS 可点「读取系统智能卡」，选择带可用密钥的 PIV 智能卡，例如已配置 PIV 的 YubiKey 5。签名验证由 macOS 处理。「选择驱动」也可选择已安装的 YubiKey YKCS11、OpenSC 或其他 PKCS#11 驱动，需要时对所选设备输入 PIN。FIDO2 SSH 密钥使用「SSH 密钥代理」。

## 数据位置

App 与 CLI 使用系统配置目录下的 `ssh-client-workbench`，也可用 `--data-dir` 指定同一私有目录。

| 系统 | 默认父目录 |
| --- | --- |
| macOS | `~/Library/Application Support/` |
| Linux | `~/.config/`，可由 XDG 配置目录覆盖 |
| Windows | `%AppData%\` |

`vault.json` 保存加密连接及策略，`audit.jsonl` 保存本机审计，`transfers/` 保存传输任务，`layout.json` 与 `behavior.json` 保存界面及行为偏好。授权绑定当前进程与连接，重启后的任务续传会重新核对目标与权限。
