# 使用说明

界面与操作细节。安装与构建见 [开发、构建与发布](DEVELOPMENT.md)，AI / CLI 用法见 [CLI 与 AI 使用](CLI.md)。

## 界面

应用图标采用单层终端标记。界面语言在「设置 → 工作区 → 界面语言」选择简体中文、English 或跟随系统，菜单与 MyGo 控件同步切换；连接名称、路径和终端内容保持原样。实现与新增文案方法见 [国际化说明](LOCALIZATION.md)。

主窗口顶栏直接显示真实连接标签和终端分组；左端切换连接侧栏，右端有传输、一个小窗开关和设置图标。小窗开关只打开 / 收起工具面板，保持上次的停靠位置；位置和独立窗口模式在小窗自己的「⋯」菜单中选择。设置是独立窗口，工作区偏好、安全与解锁、运行与后台及授权中心都在其中；关闭设置不关闭 SSH 或文件。设置导航不随主窗口连接侧栏一起收窄。主窗口四边与面板之间采用紧凑间距，状态提示以临时浮层显示，不常驻占用底部一行。

左侧单击只选择连接，每次双击都新建独立终端；切换标签保留侧栏选择及滚动。标题栏空白区域可拖动窗口，标签和操作按钮保留各自的点击 / 拖放行为；macOS窗口按钮向内留白，与标题栏居中对齐。终端与独立功能区使用同一套标签，支持拖动、右键、关闭和四向递归分栏。命令、文件、服务器状态可以停靠在上、下、左、右，也可独立成工作区标签；传输保留全局任务入口。浅深主题、线性图标、按钮和 Dialog 使用同一套原生呈现。

文件区默认一套目录树＋列表。每个文件窗口的「⋮」集中管理向右 / 向下拆分、添加本机窗口、左右 / 上下 / 网格排列，以及关闭或仅保留当前窗口；工具选项卡右侧不再显示含义模糊的加号。各窗口独立保留服务器、目录、选择与跟随设置，最多同时显示 8 个；新增本机窗口恢复本机缓存目录，即使此前该窗格切换过服务器，也不会改动其他窗口来源。多窗口之间的本机 / 服务器拖拽沿用原传输确认。排列变化只调整文件区，不自动放大或覆盖终端。来源、路径、目录树开关、上一级、刷新、新建目录、上传、下载与更多在同一行；窄窗将次级动作收进更多。计数在列表右下角，目录树延伸到底部。工具条的展开图标可将文件管理变为独立工作区标签；文件标签右键“返回停靠面板”可还原，保留目录、选择及分栏。新建文本、重命名、属性与窗口布局仍在右键 / 更多菜单。

双击服务器后立即打开终端标签，显示正在连接；再次双击建立另一独立标签，排队时显示等待。失败保留原因和重试入口；关闭加载标签会取消该次连接，后续成功不会抢走已切换的页面。服务器指纹变化需明确重新核对。

双击文件后立即创建独立编辑窗口并显示读取状态，支持取消和失败重试。标题只显示一次文件名与来源，保存 / 关闭用图标，底部显示行数、光标、UTF-8、换行格式及大小；另存为在编辑操作菜单。原生关闭与 Cmd+W 都检查未保存内容，保存期间不能关闭。内置编辑器支持 4 MiB 以内、不含 NUL 的 UTF-8 纯文本（如 txt、conf、JSON、Markdown、日志和脚本），依据内容判断，不按扩展名限制。图片、PDF、压缩包、其他二进制或非 UTF-8 文件请下载后用对应程序打开；终端的 GBK 设置不转换文件内容。

远程文件 / 文件夹右键选择「下载到本机…」，输入已存在的本地目标文件夹即可，不要求额外打开本机栏。文件夹递归下载并保留层级和空目录；任务入口立即显示扫描 / 下载进度、文件数和错误，可暂停 / 继续。也可下载到另一栏，或将远程文件夹拖到本机栏。已有同名目标不会覆盖或合并；含符号链接、特殊文件或不可移植文件名时会报错，请单独处理或分批下载。目录上传尚不支持。

工具面板的「⋮ → 停靠侧」第一个重叠窗口图标可把文件、命令和服务器状态移到独立系统窗口，也可用“视图 → 工具面板独立窗口”。新窗口可自由移动、缩放，主窗口将工具区域交还终端；选择上、下、左、右停靠图标可停靠回去。文件数据、选择、分栏和跟随状态保持，服务器状态继续跟随当前终端。关闭工具窗口只收起工具，SSH 保持连接，主窗口工具按钮可重新打开；锁定或退出会关闭独立窗口。工具操作的确认框与命令编辑框在发起窗口显示，停靠回去或关闭时保留尚未提交的表单。不会在启动、后台刷新或恢复布局时自动弹出独立窗口。

终端、独立文件管理、命令和服务器状态都是平级工作区标签。拖到另一标签上可排序或移组；拖到窗格的上、下、左、右边缘可继续拆分，形成四格、六格等嵌套布局。每个窗格独立选择标签，最后一个标签移走或关闭后自动收回空格；「终端分栏 → 合并全部分组」保留所有会话、输出和功能区状态。单组标签放在窗口顶栏，多组标签放在各自窗格顶部。

工具区内的展开动作或「⋯ → 独立到标签页」将当前功能区放进工作区；独立标签可拖回工具面板，也可右键「返回停靠面板」。停靠工具的标签拖到终端窗格四边改变停靠方向，拖到窗格中心或标签栏则独立。独立的命令和服务器状态保留打开时的服务器，切换或拖动终端不改变其操作目标；文件来源仍可明确选择本机或任一服务器。关闭独立功能区只关闭它的展示，不断开 SSH 会话。独立文本编辑仍使用原有系统窗口及未保存确认。

新建连接的「保护路径…」用宽幅多行输入，每行填写一个规范绝对路径；留空恢复默认路径，非法路径会保留草稿并显示原因。这些路径约束 AI 的结构化文件读取、下载和修改，不是任意远端命令的系统沙箱。

「视图」菜单的放大 / 缩小 / 实际大小缩放整个主窗口界面，文字与图标按缩放后的尺寸重绘而不是放大位图；macOS 为 Cmd + 「+」「-」「0」，Windows / Linux 为 Ctrl + Shift + 「+」「-」「0」（裸 Ctrl 留给终端）。比例随布局保存在 `layout.json`，只记录比例，不含连接资料。

保险库闲置锁定可在“设置 → 安全与解锁”关闭或调整，默认15分钟；手动锁定、系统锁屏和休眠仍会撤销访问。正在进行的传输保留断点，解锁后可继续。

新建 / 编辑服务器采用左侧分类、右侧编辑：常规（Normal）填写地址、登录方式及备注；加速与代理配置 HTTP / HTTPS / SOCKS5 或自有 SSH 中转并实测路径；终端设置包含编码、退格及保活；访问策略管理 AI 权限。各页独立滚动、保留输入，底部保存 / 连接固定可见；保存时会自动显示有错误的分类。切换分类不改变连接路径，也不会开启加速。

## 首次使用

macOS 本机构建位于 `build/darwin-arm64/SmallSSH.app`。首次打开创建保险库。

1. 左侧「＋」新建连接，填写名称、服务器地址、用户名和登录方式。连接 ID 自动生成；端口默认 22，直接显示在地址旁；分组可选择已有名称，也可输入新名称随连接保存；备注直接写在同一表单里，与其他位置打开的服务器备注共用同一份加密内容。分组、备注、服务器身份和 AI 访问都在表单中直接可见，不折叠、不收进二级面板。AI 访问只保留允许 / 不允许与关键操作保护，具体后果在真正授权时再说明。同一窗口支持新建、编辑及保留 / 更换登录凭据。
2. 密码方式填写服务器密码；私钥可以选择文件，也可以粘贴本机完整路径，支持 OpenSSH / PEM。本地检查格式和私钥口令，保存前再检查一次；代理方式读取公开身份并明确选定其中一把。已有密码和私钥不会在编辑时回显，修改名称等信息默认保留凭据；需要时勾选「更换登录凭据」。导入后原文件保留；以后登录使用加密库中的副本，不依赖原文件位置。取消会清理输入并取消检查；有未保存内容时，切页或切换服务器会先确认。
3. 首次保存先读取服务器指纹，弹出一个紧凑确认框（显示 SHA256）并询问是否信任；不会向目标发送登录凭据。若配置中转，则先认证已保存的中转。点「信任指纹并连接 / 保存」后把指纹写入**本机加密保险库**，不写入 `~/.ssh/known_hosts`，随后保存并连接。以后每次连接都要求指纹一致；指纹变化会先拒绝，只有主动点「重新核对服务器身份」才显示候选指纹并要求再次确认。取消首次确认不会登录，也不会保存指纹。改变地址或端口视为新目标。同一次解锁期间，保存和直接连接复用进程内已解密的会话密钥，不再重复索要主密码。只保存后也可双击服务器连接。手动终端持续到关闭、锁定或退出；每次双击服务器都会新建独立终端标签，同一服务器可同时打开多个终端，右键也可新建终端标签，断线后可在原标签重新连接。外部 CLI / AI 需要独立授权；单次请求最长 15 分钟，也可申请有期限的客户端会话，在批准范围内复用授权。成功后自动关闭表单并进入终端；保存成功但登录失败时会分别说明结果并保留可修正的表单。服务器指纹变化时先拒绝登录，使用「重新核对服务器身份」读取候选指纹，再独立核对并确认；不会自动替换已信任记录。右键连接可编辑或删除；修改及删除会撤销该服务器会话；它作为中转时，也撤销依赖该路径的授权。
4. 「文件」默认只有一套目录树和文件列表。「＋」增加第二窗口，「×」关闭并保留位置；每个窗口可选择本机或已保存服务器。进入文件窗口自动读取目录，输入路径按 Enter 跳转；点击树节点 / 双击文件夹进入。刷新按钮或 F5 更新目录，失败处可直接重试。文件列表和左侧目录树均可右键重命名 / 移动、权限 / 属性及删除，目录菜单还可新建文件夹 / 文本、刷新、返回上级或恢复跟随终端；目录只删除空目录。「权限 / 属性」用所有者 / 用户组 / 其他用户三行勾选读、写、执行，实时显示权限值；所属用户和组可选已有名称或输入数字 UID/GID。保存只作用于该目标，不递归；没有服务器权限会显示实际错误，不自动提权。根目录、符号链接和特殊文件仅查看属性。
5. 本机与服务器间可拖放普通文件，Cmd / Ctrl 多选、Shift 连选；也可右键上传 / 下载。核对目标后进入「传输」队列，支持暂停与断点续传；本机界面使用当前解锁会话签发精确操作证明，不再次索要主密码。已有文件不会覆盖，完成后已载入的目标列表自动更新。服务器互传和整目录上传尚未接通；远程整目录下载已支持，入口与限制见上文。
6. 「命令」顶部按分组 tab 切换，下面用多列小卡片排列命令；卡片只显示名称（和「全部」里的分组），不铺完整命令，双击或回车后在校对表里查看全文并发送；目录没有权限时右侧文件区直接显示拒绝原因和「重试 / 上一级」，不会继续显示上一次的旧内容。搜索和「＋」仍在一行，右键卡片可编辑、删除或切换「执行前确认」；「以后不再提醒」是**按单条命令**保存的，不会影响其他命令。双击一条命令会核对命令与目标后发送；勾选「以后不再提醒」后，没有参数、没有系统差异的命令双击即发送。命令里写 `$1`、`$2` 就会生成参数行；每个参数可填名称、选择文本 / 整数 / 数字、设置默认值，并勾选「发送时填写」。勾选时执行确认窗会预填默认值，可以改后再发送；不勾选就直接用默认值拼进命令，因此必须填写默认值。同一个参数在默认命令和各系统版本里共用。已有命令如果原来就把 `$1` 当字面文本（例如 awk），不会在升级时被改写，修改命令内容或点「识别占位符」后才转换成参数。同一个命令还可以保存多个系统版本（apt / dnf / zypper / pacman / apk / macOS / Windows），执行时按服务器状态里已知的系统自动选择，未匹配时使用默认命令；没有默认命令、已知系统又对不上时，即使关闭了提醒也会先打开核对表。参数按填写内容原样替换，不做 Shell 引号转义；需要引号时请把引号写进命令本身。主终端不再常驻额外输入栏。
7. 「服务器状态」只在面板真正显示当前终端时采集：收起面板、切到其它工具页或换到别的终端标签都会暂停远端读取，重新显示时先给出上次样本再继续更新；多个终端连同一台服务器共用一套采集，不会重复执行远端命令。概览只显示 CPU、内存、网络、磁盘 I/O 四张卡片和系统摘要，按可用宽度自动排列 1～4 列，底部较浅时切换紧凑卡片；点击卡片在原面板内查看详情，终端大小保持不变；固定在上方的“返回概览”保留原滚动位置。趋势支持最近 1 / 5 / 15 分钟与悬停数值，同一采集源共用最多 451 个紧凑样本和一份当前状态；关闭一个标签不影响其他标签，最后一个订阅离开后停止采集。断开的标签保留最后状态，退出或锁定后释放。详情包括各核心、用户态 / 系统态 / I/O 等待、内存与 Swap、各网卡速率与累计计数、块设备读写 / IOPS / 忙碌率以及文件系统容量。进程支持搜索和点击各列表头排序（进程名、PID、CPU、内存、账户、状态、运行时间）；自启服务也可按服务名、状态和启用方式排序，重复点击切换升降序并显示箭头。排序在搜索、自动刷新和标签切换后保留。系统信息和自启服务独立成页。资源每两秒更新，系统、型号和服务每 60 秒刷新；缺样本或计数重置显示等待，不画成零，断开后注明最后状态。Linux 状态接口不支持时明确说明，读取失败不影响终端；不安装额外服务器服务。进程 CPU 是 ps 的运行期间平均值，清单合并 CPU / 内存各前 32 项；非 Linux 状态接口未适配。
8. 独立文件窗内 Cmd / Ctrl+S 保存，未修改或正在保存时不会重复提交；文件窗关闭和终端标签关闭分别处理，关闭有修改的文件时先确认。工具面板「⋯」选择四边停靠、独立到标签页、系统窗口、主动放大或恢复分栏；放大时顶部也会显示“恢复分栏”按钮。面板右上角「×」完全收起；应用顶栏的工具显示按钮可恢复。快捷键为 Cmd / Ctrl + Shift + J。布局文件只存位置与尺寸，不存连接资料或命令内容。
9. 右上设置按钮打开独立设置窗，授权中心也在其中。设置使用左侧分类、右侧独立滚动内容：「工作区」管理连接侧栏、工具显示、停靠位置与恢复默认布局；「安全与解锁」管理系统验证。AI / CLI 的待处理请求会弹出授权窗并激活应用，一次一个，处理完继续下一条；窗口标题显示还有多少条，关闭但未决定的请求留在授权中心。顶栏锁形按钮和系统「安全」菜单均可锁定。锁定会撤销授权、断开会话并清除界面中的文件内容。系统验证适配与实机范围见安全文档。删除连接清除本机资料并撤销授权，不删除服务器数据。

多选文件可使用 Cmd / Ctrl 点击或 Shift 连选；右键已选项会保留整个选择，再选择“删除”。确认框显示真实数量与目标，按确认时的服务器和路径逐项执行，切换窗口不会重定向。成功项从列表移除，失败项保留，并报告成功 / 总数及原因。支持普通文件和空目录；非空目录会保留并报错；服务端仅返回通用失败时，会提示检查目录是否为空及删除权限，当前不递归删除。

## 命令参数与输入历史

双击常用命令后，发送面板会在模板里标出参数名称，例如 `pct config [$1 · ContainerID]`；下面直接填写 `ContainerID`，旁边的「历史」只列出这个参数在当前服务器、所选命令系统版本下用过的值。选择历史只回填这一项，并立即更新底部「实际发送」预览，不发送命令。也可从面板右上「编辑命令」修改模板、默认值和参数设置。

新建 / 编辑命令和运行弹窗都有「发送时询问」，可随时重新开启。关闭后，无需参数与系统选择的命令会直接执行；仍需填写参数或选择系统时保留弹窗。运行弹窗内的开关在成功「发送并执行」后保存；取消、校验失败或「填入终端」不改变已保存的选择。

每个参数保留最近 10 个不同输入，重复使用会移到最前。历史与命令一起加密保存在保险库内，重开应用后仍可使用；默认不自动选取最近值，仍以配置的默认值开始。只记录已经交给终端的单行输入，单值最多 512 字节；草稿、校验失败和取消不记录。「清空此参数历史」只清理当前目标和命令系统版本下的这一项。参数设置可取消「记录输入历史」，保存后同时清除该参数已有记录；敏感参数可使用这个选项。

底部「发送到」明确显示会话名称和实际账号 / 地址，可主动选择其他已打开终端。打开面板后切换工作区焦点不会改变目标；主动更换发送会话或系统版本会重新加载默认值和对应历史。原会话已关闭时会拒绝发送，不自动转向另一会话。

「填入终端」只接受单行命令，不追加回车，随后由你操作终端；「发送并执行」追加回车。选择历史、编辑参数及参数框内的 Enter 均不执行。多个参数时输入区可以滚动，实际命令预览、目标与发送按钮保持在底部。参数仍按已有模板原样替换，Shell 引号与转义由命令作者负责；`$1` / `${1}` 和旧 Shell / awk 字面命令保持兼容。

## 编码、代理与连接路径

新建 / 编辑连接中展开「终端、代理与连接保活」：

- 「字符编码」可选自动、UTF-8、GB18030 或 GBK。自动模式先输出 ASCII 提示，按首段非 ASCII 输出选择编码；短文本和混合编码可能有歧义，乱码时明确选择服务器编码。终端内部仍为 UTF-8；只有交互终端输入 / 输出转码，文件、SFTP 与普通 exec 输出保持原始字节。
- 「退格序列」自动默认请求 ^?（DEL），也可指定 ^H（BS）；同时设置 PTY 的 VERASE 并转换退格键字节。显式 Ctrl+H 控制输入保持，不会被默认退格设置改写。
- 「网络代理」选择不使用代理、HTTP CONNECT、HTTPS CONNECT 或 SOCKS5，填写主机和端口，可加用户名 / 密码；DNS 交给代理。密码与连接一起加密保存，编辑时默认保留同一代理的秘密，勾选更换可替换 / 清空。代理身份改变时不会复用旧密码。不使用代理不会读取系统或环境代理；连接失败也不回退直连。HTTP 和 SOCKS5 自身不加密认证，应通过可信链路使用；HTTPS 会校验证书。
- 「自有 SSH 中转」选择已保存并核对指纹的连接；中转可继续引用其他中转，整条路径最多四个 SSH 节点，不允许循环。每跳独立认证和校验指纹；第一物理跳可配置网络代理，同一个节点不能同时配置代理和中转。目标指纹探测不认证目标，但会登录必要的中转；修改 / 删除中转会撤销依赖它的活动授权。
- 「路径实测」在已有可信目标指纹后比较直连与当前中转的建连握手耗时，随后可点「按实测选择更快路径」，保存后生效。它不测持续带宽、不自动重试操作，也不承诺海外线路固定提速。当前 SSH 依赖不支持压缩，界面没有压缩开关。
- 「SSH 保活间隔」默认关闭，可设定间隔和无响应断开阈值；它用于发现失联，不负责自动重连或重放命令。

## PKCS#11 硬件密钥

登录方式选择「硬件密钥（PKCS#11）」，指定与本机架构一致的可信驱动完整路径，再点「加载驱动并读取令牌 / 公钥」。先查看令牌序列号，选择正确令牌后按设备要求输入 PIN，再次读取并选定公钥；保存时固定模块 SHA256、令牌序列号、密钥 ID 与 SSH 公钥指纹。没有 PIN 的公开枚举不尝试默认 PIN，也不会跨令牌尝试登录。驱动升级后须重新识别并保存新摘要。

实现支持 PKCS#11 RSA / ECDSA，涵盖这类接口的 YubiKey PIV、Nitrokey 和 SoftHSM；实际设备、驱动版本、触摸及 PIN 策略需要逐项实测。FIDO2 / `sk-` 继续选择「SSH 密钥代理」并使用相应 agent。私钥留在令牌内；PIN 在加密连接中保存，不在列表回显。程序不会初始化令牌、导入私钥或重试错误 PIN。

模块会以当前系统用户权限执行原生代码，只选择可信供应商的驱动。独立工作进程允许在签名卡住或取消时退出，不提供恶意驱动沙箱，也不证明设备品牌或持续插入状态。

## SSH 隧道

通过「连接 → SSH 隧道…」或连接右键「SSH 隧道…」选择方向，填写监听地址和必要的目标地址，再明确启动：

| 类型 | 数据方向 |
|---|---|
| 本地 | 本机回环监听 → SSH 服务器连接目标主机:端口 |
| 远程 | SSH 服务器回环监听 → 本机连接目标主机:端口 |
| SOCKS5 | 本机回环 SOCKS5 监听 → SSH 服务器连接客户端指定的 TCP 目标 |

监听只接受 `127.0.0.1:端口`、`[::1]:端口` 等明确回环 IP，端口 `0` 自动分配并显示实际地址；不接受通配地址或 `localhost`。远程隧道要求服务端允许 `tcpip-forward`；服务端的 `GatewayPorts` 可以改变实际绑定范围，客户端请求回环不能替代服务端配置核验。动态隧道不支持 UDP / BIND，且允许任意 TCP 目标。

隧道审批展示方向、监听和目标。监听端口可由所在机器的其他进程使用，不能把回环地址视为调用方进程隔离。只读 / 限目录会话及默认关键操作保护不开放隧道；受托方需要明确批准或符合完整无限制会话范围，始终受服务器策略约束。

隧道使用独立 SSH 连接；关闭管理面板后仍在后台运行，需点击「停止」结束。锁定、退出、撤销、到期及发起客户端断线都会关闭监听和已接受的连接。桌面所有者隧道持续到上述结束条件；一次性外部 CLI 隧道最多 15 分钟，Ctrl+C 立即关闭。CLI 示例见 [命令说明](CLI.md#连接选项硬件枚举与隧道)。

## Docker 与 Compose

Docker 在「服务器状态 → Docker」中管理：容器右键 /「⋯」统一提供日志与详情、容器终端、启动、停止和重启。点击卡片名称或双击列表可查看日志；日志留在原工具区，支持搜索、复制、暂停接收及跟随最新，返回不改变终端大小。容器终端默认 sh，也可选择 bash，打开普通终端标签；文件区仍通过 SSH 浏览宿主机，会标明「跟随宿主机」。

Compose 一张卡代表一个项目，汇总运行状态、总 CPU / 内存并预览各容器状态；点击查看项目容器，详情右上角「⋯」提供启动、停止、重启与更新；启动 / 停止 / 重启先确认整项目服务范围，更新先选择服务并检查计划，再开始更新。默认选择正在运行的服务；沿用服务器配置里的镜像标签或摘要，不替换为 latest。下载镜像后再次核对配置，随后重建所选服务并检查运行 / 健康状态；不删除数据卷、旧镜像或其他容器。更新在后台执行，右上「任务中心 → 服务器操作」查看阶段、输出与结果，任务不会自动弹出面板。中断等待时需核对远端实际状态；数据库数据不提供自动回滚。适用范围及 CLI 用法见 [Docker 与 Compose 流程](SERVER-MANAGEMENT.md#docker-日志容器终端与-compose-更新)。

## 终端

终端沿用 Ghostty 编码和渲染，支持 32 MiB 输出回滚缓冲、应用光标模式、备用屏幕、分段 UTF-8、组合字符及程序请求的括号粘贴。方向键与 Ctrl+R 交给远端 Shell 使用它已有的历史记录；不会修改远端启动文件或把历史文件伪装成以前的屏幕输出。菜单在 Windows / Linux 使用 Ctrl+Shift+C / V / A 和 Ctrl+Shift+W，不抢终端 Ctrl+C、Ctrl+R、Ctrl+W、Ctrl+Z 等控制键。macOS 使用 Command 复制 / 粘贴，Option 作为终端 Alt。

参考：[Bash 历史快捷键](https://www.gnu.org/s/bash/manual/html_node/Commands-For-History.html)、[Ghostty Shell Integration](https://ghostty.org/docs/features/shell-integration)、[systemctl 的启用与运行状态](https://www.freedesktop.org/software/systemd/man/latest/systemctl.html)。此项目使用 libghostty-vt，并不自动拥有 Ghostty 完整应用的远程 Shell 集成。

## 授权的边界

外部 CLI / AI 的单次请求、首次会话批准及续期仍需所有者通过主密码或系统验证确认；获批会话内的子操作按批准范围签发，不逐条要求验证；本机桌面明确发起的连接、文件操作和传输使用已解锁会话，只签发本次具体操作，锁定或退出后失效。取消或验证失败不会放行，也不会静默降级。没有相应硬件的终端可使用主密码。创建正式保险库要求主密码至少 12 字节；`123123` 仅用于单独的开发测试库，创建策略没有为测试降低。

首次在可信桌面或自行启动的 agent 解锁后，外部 CLI / AI 自动校验本机配对的代理身份，无需复制公钥。更换保险库时在「设置 → 安全与解锁 → 配对 / 修复本机 CLI」明确更新；配对不授予服务器权限。连续命令使用 `smallssh exec 连接ID`（每行一条，`:quit` 退出）；结构化访问使用常驻 `session serve` 或同进程 SDK；会话仅绑定当前进程实例与活连接，断线、退出或重启后重新批准，旧会话文件不能恢复。见 [CLI 使用](CLI.md)。

## 测试预览库

测试预览目录 `ssh-client-workbench-preview-qa` 会明确标为测试保险库；连接表单仅允许本机测试地址，避免把真实服务器凭据填进弱口令测试库。独立可复用的凭据库与密钥生成尚未实现；现有密码 / 私钥保存在各自加密连接中，添加连接无需先完成另一套凭据创建流程。

## 服务器备注与服务检测

服务器右键「备注…」或“连接 → 服务器备注”可记录用途与维护事项，手写内容和自动概览分开加密保存。点「检测服务和域名」按需读取当前账户可见的运行服务、Docker / Compose 容器、监听地址与常见静态站点配置，并对发现的域名做本机解析核验。概览仅列出应用服务和关联域名：正常运行不重复标注，只标出已知停止、异常或解析地址不同的项目。系统服务、端口、IP、配置路径和检测范围放进默认折叠的「检测详情」；老版本清单和用途摘要也可直接在本地整理显示。服务识别使用独立维护的[常见应用清单](SERVICE-CATALOG.md)，覆盖 Web、Java、Node.js、Python、Ruby、PHP、Go 常见产品等；支持版本和实例变体，只在本地匹配，不增加服务器请求。服务名根据已知应用、容器和自定义服务配置来源整理；未识别的发行版服务留在详情，避免把磁盘工具、系统认证等组件当成业务。手动检测时仅增加一次批量服务路径读取，不逐个请求，不读取启动参数或环境变量，不据此推断网站内容、代理路由、证书续期或公网可访问。生成后可检查并点击「保存备注」，不会覆盖手写内容。检测有超时和数量上限，不读取容器环境变量、不展开自定义 include 或容器内配置；解析核验不是反向域名枚举，CDN / 代理可能显示地址未匹配，也不代表网站不可访问。连接目标变化会标记旧概览，锁定会关闭备注并取消检测；备注不进入公共 AI 连接清单。

自动概览不轮询，同一连接目标每分钟最多手动启动一次（取消、关闭再打开也保留冷却），总超时 25 秒；最多发现 32 个域名，解析并发最多 4 个，每个最长 2 秒。服务器状态复用已授权的 SSH 连接，同一保存连接、SSH 用户、实际地址与已核对主机指纹共用一套采集、最新快照和趋势缓存：常规采集间隔为基础资源 2 秒、Docker 资源 10 秒、系统与容器清单 60 秒，从上一轮完成后计算；采集中断后的接替也保留 2 秒冷却。多开终端订阅同一份结果，新标签先读取缓存；当前采集连接关闭时由其他已授权连接接替，不额外登录。最后一个订阅离开、锁定或退出后停止。不同保存连接条目和账号的数据保持隔离；全局采样限额仍限制重复地址配置的请求总量。采样不重叠，等待可以取消；Docker 不可用时每分钟再试，其他状态失败按 10、20、40、60 秒退避，不影响终端输入。

## 数据位置

为兼容已有资料，默认继续使用当前用户系统配置目录下的 `ssh-client-workbench`：macOS 为 `~/Library/Application Support/ssh-client-workbench`，Linux 通常为 `~/.config/ssh-client-workbench`，Windows 为 `%AppData%\ssh-client-workbench`。桌面和 CLI 均支持 `--data-dir` 指定同一个私有目录。

`vault.json` 保存加密连接和每台服务器的自动化策略；连接右键“AI 访问…”可禁止 AI / CLI 或配置关键操作保护与命令护栏。禁止访问时不弹审批，只记录拒绝；已有授权随策略更改失效。授权中心“历史”读取持久记录，包含申请方、服务器、操作、结果和拒绝原因，支持分页与重启保留；`audit.jsonl` 保存操作摘录和进程实例，不含口令、私钥、ticket 或输出，单文件8 MiB并保留一个归档。`device-unlock.json` 保存系统保护的设备解锁材料，不保存主密码或明文保险库密钥。Unix 使用私有目录及套接字；Windows 使用限制到当前用户 SID 的命名管道。管理 RPC 仅使用私有 IPC；明确启动隧道时会建立回环 TCP 监听。程序不向服务器安装组件。

`transfers/` 保存任务元数据（包含本地/远程路径、摘要和进度，无凭据或授权票据），采用私有目录。部分文件保留在目标目录，校验完成后无覆盖提交。每次续传重新申请授权，前缀或源文件改变会报错。
