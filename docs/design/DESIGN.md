# SmallSSH 桌面设计

可编辑设计源位于 [smallssh.smallpen](smallssh.smallpen/)。[页面目录](pages.json) 记录各页面的入口、承载方式、状态、操作和 Go 源码位置。产品行为见 [使用说明](../USAGE.md)，需求见 [REQUIREMENTS](../REQUIREMENTS.md)。

## 当前交互

- **工作台**　顶部标签切换终端、VNC 和已打开的功能。画布模式支持拖动和四向分栏，卡片只显示当前视图的标题和操作。标签模式聚合显示当前视图。文件、命令和服务器状态可停靠，也可打开为标签或独立工具窗。
- **服务器侧栏**　新建连接位于左上角。首帧读取连接时显示骨架行。分组和连接松手即到新位置，后台异步保存。失败时恢复已确认顺序并提示。「已有私钥」可粘贴文本或选择文件，界面只显示导入状态和公钥指纹。保存仅写入配置，双击连接时才拨号。首次连接及主机指纹变化时，沿用本次线路核对服务器身份。
- **线路与转发**　设置中的「加速与代理」集中管理可复用的线路。连接引用线路 ID，编辑后下次连接生效。右上角「端口转发」进入运行列表，服务器右键可直接新建。新建界面用三张路径图选择用途，地址和端口在节点中填写，路线从连线上的加号选择，点中转旁的关闭按钮恢复本次直连。选本机 SOCKS5 时单独显示其地址，访问远端服务时在图下提供启动后打开网页的选项。右键终端连接与加号菜单均可选择「新建 SSH 中转」，从已保存的服务器中选一台供本次使用。启动后在列表显示实际入口。
- **密钥登录**　「硬件密钥」可直接读取 macOS 系统 PIV 智能卡，也能选已安装的 YubiKey YKCS11 或 OpenSC。系统智能卡的 PIN 由 macOS 处理。使用 PKCS#11 驱动时，选设备后才提供 PIN。「SmallSSH 密钥」在连接表单中可生成密钥、指定签名验证方式和复制公钥。
- **文件与任务**　文件管理同时显示目录树、列表和选择状态，可跟随终端或选择来源。点击表头排序，窄窗可从「…」按修改时间排序。同一来源内可拖到文件夹、目录树节点或「上一级」移动，拖动时高亮可用落点，结果显示在列表下方。远程窗格用系统选择器上传，也接收从系统文件管理器拖进来的文件，落点决定目标目录。同名上传用小对话框显示目标和「跳过」「覆盖」。编辑单个文本文件使用独立原生窗口。任务入口位于主窗顶栏，完成记录可单条移除或清空。
- **服务器状态**　资源概览、进程、服务、系统信息、端口和 Docker 可在状态面板切换。时间范围放在状态栏右侧更多菜单。
- **VNC**　远程桌面显示在工作区标签，使用同一连接进入全屏。常用操作用图标，在显示空间不足时收进更多菜单。
- **授权中心**　待确认、当前授权和审计记录在设置内切换。服务器操作授权与 SSH 密钥使用授权分别管理。当前受控会话可实时调整中风险文件确认，审计详情保留当时的勾选和切换记录。较宽窗口在右侧展示详情，窄窗口展示在列表下方。

## 窗口和后台

| 内容 | 承载方式 |
| --- | --- |
| SSH 终端、VNC、打开为标签的工具 | 主窗口顶部工作区标签 |
| 文件、命令、服务器状态 | 工具区、画布卡片、工作区标签或独立工具窗 |
| 设置、文本文件编辑 | 独立原生窗口 |
| 新建连接、主机身份确认 | 当前宿主内弹窗 |
| 授权确认 | 独立审批窗口，或设置中的授权中心 |

| 动作 | 行为 |
| --- | --- |
| 关闭窗口时退出 | 关闭工作台并锁定连接服务 |
| 关闭窗口后驻留 | 隐藏工作台，已有会话仍受原授权期限和闲置设置约束 |
| 退出应用、主动锁定、系统锁屏或休眠 | 锁定连接服务并撤销会话 |
| 最小化 | 保留窗口、会话和原授权状态 |

驻留期间可通过启用的 Dock 或菜单栏入口恢复窗口，至少保留一个入口。工作区呈现方式在「设置 → 工作区」调整，关闭行为在「设置 → 运行与后台」调整。

## 可编辑设计

- 实现连接、授权等画板时，先记录用作验收基准的 SmallPen 修订，再从 `view --as spec` 读取绑定、尺寸和控件约束。用相同主题、窗口尺寸和示例状态比较 App 离屏截图与画板。App 的缺陷修在实现处，画板的交互意图以评审结果为准。
- App 编译时通过 [tokens.go](tokens.go) 读取正式包的 `tokens.css`。原生基础配色、连接窗和字段尺寸、设置选中态、主要审批窗口尺寸及审计结果列已有直接绑定。修改这些 Token 后通过常规构建进入 App。`check` 同时跑分组箭头的离屏笔画居中回归。
- 连接和授权画板按本机 App 的离屏截图及桌面源码校对。连接弹窗的宽度上限为 820，高度为 620，分类和底部操作固定。表单可以独立滚动。首屏样例保留长表单的滚动边界。
- 授权中心使用设置窗口的横向标签。审计记录在宽窗关闭详情时使用整宽表格，打开详情后切换为左侧紧凑列表和右侧详情。独立服务器操作审批使用 420×400 的内容区。
- `index.html` 保存设计包入口，`tokens.css` 保存主题、字体和尺寸。共享组件在 `components/`，页面在 `pages/<模块>/`。
- 修改页面时同步 [页面目录](pages.json)，并优先复用现有组件和 Token。
- SmallPen 渲染使用 [assets/fonts](smallssh.smallpen/assets/fonts/) 中的 WOFF。[font-notices](font-notices/) 保存字体来源、许可证和图标字形映射。
- 日常查看复用用户已运行的 SmallPen 工作区。设计使用合成内容，应用截图用 [离屏测试](../DEVELOPMENT.md#需要额外依赖的测试) 生成。

当前 CLI 的帮助和内置 Skill 给出维护方式。

```sh
smallpen help skills --json
smallpen check docs/design/smallssh.smallpen --json
smallpen check docs/design/smallssh.smallpen --render --all-themes --json
smallpen view docs/design/smallssh.smallpen --as text --json
smallpen view docs/design/smallssh.smallpen --page '08 设置 / 授权中心 · 历史' --as png --theme appearance/light --json
smallpen changes docs/design/smallssh.smallpen --since REVISION --json
```

## 连接与授权 · 优化评审

正式包内的「连接与授权 · 优化评审」画布用于比较候选稿。对照基线为已做过 App 离屏核对的修订 `0c74ef5341d04dcf7f257189f61c55521dc1f2986277e66248b20bf0fd685aad`。候选稿采用现有明暗主题、按钮、输入控件和窗口尺寸，沿用 [页面目录](pages.json) 对应的业务流程。示例服务器、私钥路径及授权记录均为合成数据。

- 连接按连接信息、登录身份和备注组织。端口紧邻地址，用户名与登录方式同排，导入和检查贴着各自的凭据字段。窄窗保留完整的主要操作。
- 登录方式保留五种入口，共用连接字段的布局固定。密码使用原有显隐控件，已有私钥把导入、口令和检查放在同一区。SmallSSH 密钥呈现签名验证与复制公钥，SSH 密钥代理呈现公钥选择和指纹。macOS 系统智能卡的 PIN 由系统处理，选定 PKCS#11 设备后表单才出现设备 PIN。
- 连接内的「加速与代理」先显示本机、实际经过的代理或跳板机以及目标服务器，再呈现所选线路的设置和握手实测。设置窗口中的同名入口管理共用线路，在列表就能看到协议、地址和引用数。线路编辑覆盖手输代理、导入代理和 SSH 跳板机。代理导入的格式说明旁有悬停提示，区分分享链接和节点 JSON 支持的协议。
- 待确认先显示目标和权限范围。配对码在决定前用带底色的独立核对区展示，数值加粗，授权中心和独立弹窗共用样式。单次会话操作直接核对命令或路径。当前授权分为服务器操作和密钥两组，每组保留到期时间和管理入口。
- 受控授权关闭「确认中风险文件操作」时，在开关下方显示琥珀色说明。授权范围内符合条件的文件操作跳过逐项确认，未知命令仍需确认，高风险操作仍会被拒绝。重新开启后收起说明。待确认和当前授权使用同一条文案。
- 审计保留可横向比较的记录表。详情先展示实际命令和结果，再分组展示申请时的规则、当前规则与来源记录。
- 连接流程展示保存后从服务器列表打开、首次核对指纹、连接中和进入终端。普通超时可在当前标签重试，指纹变化先显示旧记录和新指纹。编辑时保留凭据是默认状态，主动勾选更换后才显示新密码字段。
- 独立审批窗口把目标、权限和期限放在前面，验证失败时就近给出主密码入口。维护准备与本次操作确认各自展示授权范围。到期结果出现在审计记录，当前有效授权区显示各类授权的空态。
- SSH 密钥使用授权先显示调用应用、密钥和本次允许的请求。请求附带主机指纹时可展开核对，无法识别时说明主机未知。可仅确认一条请求，也可一次确认当前这一组。限时许可可从密钥设置或使用通知开启，范围覆盖整把密钥。
- macOS SSH 密钥代理构建时读取正式包的颜色、尺寸和字体，并在请求核对页留出 40 pt 的系统验证入口。「仅当前指纹」使用嵌入式系统控件，「macOS 验证」由系统提供验证及登录密码入口。
- [授权验证底栏](smallssh.smallpen/components/授权验证底栏.html) 供 SSH 密钥、独立服务器操作审批、维护准备、会话内操作和授权中心共用。初始状态点击最右侧的指纹直接验证，等待时图标在原位显示状态。展开主密码后，支持系统验证的请求把图标放在密码框右端，紧邻显隐按钮。点图标清空已输入的密码，并在原处等待系统验证。底栏显示「拒绝」和「允许」，仅当主密码已填且没有验证在进行时，可以点「允许」。仅支持主密码的请求直接显示密码框和决定按钮。
- macOS 的系统验证入口使用 Touch ID，为 `LAAuthenticationView` 保留 40 × 40 pt。Windows 入口明确写「Windows Hello」，可用的 PIN、人脸和指纹由系统弹窗决定。Linux 入口写「指纹验证」，fprintd 等待读取时在当前窗口提示把手指放到读取器，未匹配时可以再次发起验证。
- 保险库主密码用于解锁 SmallSSH 和审批服务器操作。SSH 密钥选择「macOS 验证」时，macOS 负责弹窗和验证，可以根据系统设置使用 Touch ID 或 Mac 登录密码。「仅当前指纹」保护的密钥要求符合创建时的指纹策略。
- [授权验证样式对照](smallssh.smallpen/pages/11%20连接与授权评审/授权验证%20·%20样式对照.html) 并排展示 App 的待决定、等待指纹、主密码状态和 macOS 密码系统窗口示意。系统弹窗随系统版本与设置呈现，设计稿使用合成数据说明输入位置。
- 审批的退出按钮是「拒绝」，验证中也在原位。Esc 可停止当前验证并保留待处理申请。保险库解锁过程的退出按钮是「取消」，停止后保持锁定。SSH 密钥使用请求的系统窗口用「拒绝」，主动开启密钥限时许可时用「取消」。Touch ID 状态由控件原位呈现。
- SSH 保活默认关闭。启用后分别显示探测间隔和单次探测的等待上限。网页可切换所有预设间隔，30 秒示例可进一步对照三个等待倍数。超时提示写明断开后需要手动重连。

原型可切换登录方式、走读公钥与设备选择、选择连接线路、预览握手结果、打开共用线路的创建与编辑，并走查连接成功与重试、保活开关、授权验证与审计。离线预览用点击服务器行对应 App 的双击动作，使用合成连接结果和审批状态。系统验证及真实保存以 App 为准。
