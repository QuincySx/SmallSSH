独立原生窗口

设置

入口：主窗右上设置或系统菜单

操作：固定导航：工作区、安全与解锁、运行与后台、授权中心；关闭

状态：分类切换、滚动、验证中取消

边界：实际窗口已有；原型不等于独立公钥向导

源码：internal/desktop/settings_window.go; internal/desktop/settings.go

设置窗口分类

工作区设置

入口：设置→工作区

操作：语言、侧栏和工具显隐、停靠位置、恢复默认布局

状态：明暗/语言切换、布局恢复确认相关状态

边界：自定义主题/字体/快捷键设置尚未实现

源码：internal/desktop/settings.go; internal/desktop/settings_language.go

画布：08 设置 / 工作区

安全与解锁

入口：设置→安全与解锁

操作：闲置锁定、系统验证启用/停用与重测、主密码确认、本机代理身份与CLI配对

状态：不可用、验证中、取消、密码错误、系统验证反馈

边界：设备/平台可用性不同；不等同服务器登录公钥

源码：internal/desktop/workspace.go; internal/desktop/idle.go; internal/desktop/settings.go

画布：08 设置 / 安全与解锁

运行与后台

入口：设置→运行与后台

操作：驻留方式、窗口关闭行为、托盘/Dock等系统可用选项

状态：托盘不可用、后台关闭、平台差异

边界：独立后台架构仍有后续需求，勿等同UDP加速

源码：internal/desktop/settings_presence.go; internal/desktop/presence.go

本机代理身份配对

入口：安全与解锁→信任本机代理

操作：核对/复制公钥指纹；确认替换本机代理配对

状态：首次配对、不同身份、错误

边界：仅信任本机代理，不授予服务器访问

源码：internal/desktop/workspace.go

画布：08 设置 / 本机 CLI 配对确认

设置窗口分类；请求也可独立弹窗

授权中心

入口：设置→授权中心；新授权请求通知

操作：待处理、活动、历史；按请求审阅与授权

状态：无请求、多个请求/紧凑选择器、过期、断连

边界：认证和票据绑定目标/期限；数据更新不应抢焦点

源码：internal/desktop/approval_center.go; internal/desktop/approval.go

画布：08 设置 / 授权中心 · 待处理、08 设置 / 授权中心 · 活动、08 设置 / 授权中心 · 历史

授权中心子页/请求弹窗

待处理授权

入口：授权中心→待处理，或新请求弹窗

操作：核对请求者、服务器、动作/范围、期限，批准或拒绝；必要时系统认证或主密码

状态：等待、验证、失败、拒绝、取消、目标过期

边界：只读/完整与操作范围不同；不做无确认的全局授权

源码：internal/desktop/approval_review.go; internal/desktop/approval_auth.go; internal/desktop/approval_notifications.go
