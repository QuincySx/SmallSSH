SmallSSH · 页面与承载地图

设计目录，不是 App 内的新页面。以正式源码和需求状态为准。

Docker子页

容器

入口：Docker→容器

操作：容器卡片/表格、启停/重启、日志详情、sh/bash终端

状态：运行/停止、失效身份、操作确认/错误

边界：以完整容器及daemon身份校验，不能删除容器

源码：internal/desktop/docker.go; internal/desktop/docker_dialog.go

画布：07 Docker / 容器

镜像

入口：Docker→镜像

操作：搜索、排序、镜像名称/标签/ID/大小/创建时间

状态：空、采集不可用

边界：镜像删除未实现

源码：internal/desktop/docker.go

画布：07 Docker / 镜像

Docker子页/项目详情

Compose项目

入口：Docker→Compose

操作：项目卡片、容器子状态；启动/停止/重启、更新计划与任务

状态：数据不完整、计划变化、更新中/失败、成员变化

边界：新建项目、编辑Compose文件、自动回滚未实现

源码：internal/desktop/compose_projects.go; internal/desktop/compose_work.go

画布：07 Docker / Compose 项目

工具区内详情

容器日志与详情

入口：容器菜单→日志/详情

操作：日志/详情切换、行数、搜索、复制、暂停/跟随；容器终端

状态：加载、失败、截断、容器已停止

边界：日志有界；容器终端为真实PTY

源码：internal/desktop/docker_dialog.go

画布：07 Docker / 容器日志与详情

模态弹窗/全局任务

Compose更新确认与任务

入口：Compose项目→更新

操作：确认服务器及已发现服务、计划核对、下载、复核与重建；查看任务

状态：成员变化、来源不完整禁用、分阶段失败/取消

边界：不承诺自动回滚，不扩大到未选容器

源码：internal/desktop/compose_work.go

画布：07 Docker / Compose 更新确认

弹窗/独立备注视图

服务器备注

入口：服务器右键→备注

操作：查看和编辑服务器备注

状态：读取中、失败重试、保存中、冲突/未保存确认

边界：备注与登录凭据分离；不推断服务器实时信息

源码：internal/desktop/server_notes.go

画布：09 工具 / 服务器备注
