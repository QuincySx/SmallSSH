独立原生文件窗口

单文件编辑

入口：文件列表打开文本文件

操作：语法高亮、搜索、编辑、保存、另存为；标题/来源/状态栏

状态：后台加载、取消/重试、格式不支持可下载、未保存关闭确认、保存中/失败/冲突

边界：仅≤4 MiB UTF-8文本；非文本不伪装成文本编辑；真实文件访问不属于离线样例

源码：internal/desktop/editor_window.go; internal/desktop/file_open.go; internal/desktop/filebrowser.go

传输与任务中心

入口：顶栏任务图标

操作：排队、进度/速率、暂停、继续/重试；服务器操作任务

状态：空、等待、运行、失败、完成、扫描目录

边界：传输不作为dock独立tab；续传包含校验

源码：internal/desktop/transfer_activity.go; internal/desktop/workspace.go; internal/desktop/compose_work.go

工具面板分类

常用命令

入口：工具→命令

操作：分组/搜索、选择、新建/编辑/删除、向指定终端填入或发送

状态：空、筛选无结果、加载/错误、会话不可用

边界：批量执行/跨服务器广播未实现

源码：internal/desktop/commands.go

服务器状态

入口：工具→服务器状态

操作：概览、进程、自启服务、系统信息、Docker、端口

状态：无会话、采集中、采集失败/过期、断开保留最后值

边界：只支持Linux现有采样；不新开监控登录

源码：internal/desktop/diagnostics.go; internal/desktop/status_resources.go

状态分类/详情面板

资源概览与详情

入口：服务器状态→概览；点CPU/内存/网络/磁盘

操作：趋势时间范围、CPU/内存/网络/磁盘卡片，详情和返回

状态：无样本、未知、过期、窄布局

边界：进程CPU为ps平均；GPU未实现

源码：internal/desktop/status_resources.go; internal/desktop/status_chart.go

服务器状态子页

进程

入口：服务器状态→进程

操作：搜索、排序、查看PID/账户/CPU/内存；TERM/KILL

状态：加载、无数据、失效PID、授权与操作确认、失败

边界：操作先确认目标并验证进程生命周期

源码：internal/desktop/diagnostics.go; internal/desktop/server_management.go

画布：06 状态 / 进程

自启服务

入口：服务器状态→自启服务

操作：搜索、排序，systemd启停/重启和自启开关

状态：无服务、非systemd回退、确认、操作失败

边界：OpenRC/SysV为自启清单回退

源码：internal/desktop/diagnostics.go; internal/desktop/server_management.go

画布：06 状态 / 自启服务

系统信息

入口：服务器状态→系统信息

操作：系统/硬件、各核、网络接口/地址、磁盘与I/O

状态：数据未知、不可用、长文本换行

边界：非Linux未适配；GPU未实现

源码：internal/desktop/status_resources.go

画布：06 状态 / 系统信息

端口

入口：服务器状态→端口

操作：非回环监听/当前外部连接切换、TCP/UDP、IPv4/IPv6、端点、进程/PID、搜索排序

状态：工具不可用、部分进程不可见、解析不全、结果截断、无结果

边界：非回环/通配不等于公网可达；不推断连接发起方

源码：internal/desktop/ports.go; internal/monitor/ports.go

状态：未安装、无权限、空、加载/失败、资源过期

边界：容器/镜像删除未实现
