主窗四边停靠、平级工作区标签或系统窗口

工具面板

入口：顶栏单一小窗开关；工具面板自己的布局菜单

操作：四边停靠、独立为工作区标签、拖回停靠；系统窗口、放大和收起

状态：隐藏、右侧空间不足回退底部、独立窗

边界：同一套工具状态；不是同时复制多个实例

源码：internal/desktop/filepanes.go; internal/desktop/tool_window.go; internal/desktop/layout.go

画布：02 工作台 / 终端与底部文件、02 工作台 / 小窗布局菜单

主工作区标签

文件管理大标签

入口：工具面板“在标签页打开文件管理”

操作：完整文件工作区；标签右键返回停靠、关闭

状态：选中/未选、返回停靠

边界：不是新的OS窗口；不复制传输任务

源码：internal/desktop/file_workspace.go; internal/desktop/workspace_menu.go

画布：04 文件 / 文件大标签

居中模态弹窗

新建/编辑连接

入口：服务器侧栏添加/右键编辑

操作：分类常规、加速与代理、终端设置、访问策略；取消、保存/保存并连接

状态：加载备注、验证错误定位分类、提交中禁改、未保存确认

边界：既有密码保留或明确更换；不包含自动接收指纹

源码：internal/desktop/connections.go; internal/desktop/connection_sections.go

画布：03 连接 / 常规与密码

连接弹窗分类

常规与登录身份

入口：新建/编辑连接→常规

操作：名称、地址、端口、可创建分组、用户名、认证方式、备注；私钥文件选择与检查

状态：密码/私钥/agent/PKCS#11分支；保留/更换已有凭据；备注读取失败重试/部分保存

边界：FIDO2/sk通过agent；未实现keyboard-interactive/MFA；实际设备仍需验收

源码：internal/desktop/connections.go; internal/desktop/connection_options.go

画布：03 连接 / 常规与密码、03 连接 / 硬件认证

加速与代理

入口：连接→加速与代理

操作：HTTP/HTTPS CONNECT、SOCKS5代理；已保存SSH中转；握手耗时比较

状态：无代理、代理凭据、测量中/失败/结果

边界：UDP双端加速和SSH压缩未实现；测量不代表吞吐

源码：internal/desktop/connection_options.go

画布：03 连接 / 加速与代理

终端设置

入口：连接→终端设置

操作：编码、退格序列、SSH保活间隔及无响应阈值

状态：自动与显式编码、禁用保活、输入验证

边界：编码仅转换终端；不改变文件字节

源码：internal/desktop/connection_options.go

画布：03 连接 / 编码与保活

服务器访问策略

入口：连接→访问策略或服务器菜单AI访问

操作：开关AI访问、关键操作保护、保护路径编辑

状态：关闭保护二次确认、输入错误

边界：护栏非不可绕过安全边界

源码：internal/desktop/connection_policy.go

服务器身份确认

入口：首次连接、指纹变化时重新核对
