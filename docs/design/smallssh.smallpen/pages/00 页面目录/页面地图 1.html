SmallSSH · 页面与承载地图

设计目录，不是 App 内的新页面。以正式源码和需求状态为准。

主窗锁定页

创建本机保险库

入口：首次启动且无本机保险库

操作：输入并确认主密码；创建保险库

状态：密码不一致、创建中、错误

边界：非服务器密码；不是公钥安装向导

源码：internal/desktop/locked.go

画布：01 访问 / 创建保险库

解锁保险库

入口：启动已存在的保险库或手动锁定后

操作：主密码或已启用系统验证解锁；切换密码方式

状态：系统验证就绪、密码输入、密码回退；验证中、取消、重试、失败

边界：系统认证依平台与设备；锁定后关闭会话

源码：internal/desktop/locked.go; internal/desktop/unlock_auth.go

画布：01 访问 / 解锁、01 访问 / 系统验证解锁、01 访问 / 系统验证密码回退

主窗口

工作台

入口：解锁成功

操作：服务器侧栏、顶栏真实终端标签、单一小窗开关（位置在小窗菜单设置）、全局任务、设置；缩放、拖分栏

状态：空服务器、未选择、已选择无会话、窄窗回退、锁定

边界：不等于独立设置或工具窗口

源码：internal/desktop/app.go; internal/desktop/workspace_menu.go; internal/desktop/layout.go

画布：02 工作台 / 终端与底部文件

主窗侧栏/紧凑栏

服务器列表

入口：工作台左侧

操作：添加、搜索、分组展开；单击选择、双击新终端；右键连接、文件、编辑、AI策略、备注、隧道、删除

状态：无连接、搜索无结果、折叠、连接中可取消

边界：收藏及拖动排序未实现

源码：internal/desktop/connection_rail.go; internal/desktop/layout.go

画布：02 工作台 / 终端与底部文件

主窗顶栏标签+终端面板

终端与会话组

入口：双击服务器或新建终端

操作：终端与独立功能区共用标签；拖动排序、跨组、四向递归拆分与合并

状态：排队、连接中、取消、失败重试、断开、主机指纹变化

边界：分组不是多个独立工具实例；不提供批量广播

源码：internal/desktop/terminal_group_view.go; internal/desktop/terminal_layout.go; internal/desktop/connection_pending.go

画布：02 工作台 / 终端与底部文件、02 工作台 / 连接中、02 工作台 / 连接失败、02 工作台 / 双终端分组

主窗终端面板

终端空态

入口：无活动终端

操作：无服务器引导添加；有服务器未选引导搜索；选定后连接终端

状态：无服务器、未选/过期选择、已选

边界：不自动连接；有效性来自完整服务器列表

源码：internal/desktop/terminal_group_view.go

画布：02 工作台 / 未选择服务器
