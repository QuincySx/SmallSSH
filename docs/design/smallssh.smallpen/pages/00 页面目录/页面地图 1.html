主窗锁定页

创建本机保险库

入口：首次启动且无本机保险库

操作：输入并确认主密码；创建保险库

状态：密码不一致、创建中、错误

边界：非服务器密码；不是公钥安装向导

源码：internal/desktop/locked.go

画布：01 访问 / 创建保险库

解锁保险库

入口：启动已存在的保险库或手动锁定后

操作：主密码或已启用系统验证解锁；切换密码方式

状态：系统验证就绪、密码输入、密码回退；验证中、取消、重试、失败

边界：系统认证依平台与设备；锁定后关闭会话

源码：internal/desktop/locked.go; internal/desktop/unlock_auth.go

画布：01 访问 / 解锁、01 访问 / 系统验证解锁、01 访问 / 系统验证密码回退

主窗口

工作台

入口：解锁成功

操作：默认卡片画布；右侧独立开关文件、命令、状态；任务统一从顶栏全局入口打开；平铺或标签聚合；视图可共享分栏，保持源会话与队列；两种模式均保留顶部工作区选项卡，切换定位对应视图；画布中不合并或重排分栏

状态：空服务器、未选择、已选择无会话、窄窗回退、锁定；顶部标签选中、跨分栏定位、溢出横向滚动

边界：不等于独立设置或工具窗口；顶栏高48，常规图标按钮32×32；终端与功能卡片标题高32，单标题左留16、右留12，卡片标题显示当前视图；画布模式不得隐藏顶部选项卡，视图切换仅在窗口顶部；卡片内部不显示选项卡；顶部选中标签底色为6%强调色，活动画布标题底色为3.5%，文字/状态点保留；顶栏首个标签相对主内容左边界内缩8，不向侧栏探出；随侧栏宽度调整，紧凑macOS原生控件区优先；全高侧栏背景与工作区、右侧按钮共用8外边距，宽度共用同一计算规则

源码：internal/desktop/app.go; internal/desktop/workspace_menu.go; internal/desktop/layout.go; internal/desktop/workspace_canvas.go; internal/desktop/terminal_group_view.go; internal/desktop/components/theme.go

画布：02 工作台 / 终端与底部文件、02 工作台 / 四个混合分栏、02 工作台 / 六个混合分栏、02 工作台 / 画布与功能开关、02 工作台 / 画布与标签混排、02 工作台 / 标签聚合

主窗侧栏/紧凑栏

服务器列表

入口：工作台左侧

操作：搜索、分组展开；单击选择，双击或选中后按 Enter 打开新终端（经未保存连接守卫）；方向键 / Home / End 跳过分组标题；右键连接、文件、编辑、AI策略、备注、隧道、删除；新建连接位于顶部左侧，紧邻连接侧栏开关；终端通过服务器操作、菜单或快捷键创建

状态：无连接、搜索无结果、折叠、连接中可取消

边界：收藏及拖动排序未实现；侧栏Surface背景从窗口顶部延伸到底部，四周8且与右侧按钮外边距统一，16圆角；列表内边距6、搜索框28；展开/收起共用头像槽和滚动状态，侧栏不常驻整行新建

源码：internal/desktop/app.go; internal/desktop/connection_rail.go; internal/desktop/layout.go; internal/desktop/workspace_menu.go; internal/desktop/components/sidebar_split.go; internal/desktop/components/theme.go

画布：02 工作台 / 终端与底部文件

主窗顶栏标签+终端面板

终端与会话组

入口：双击服务器或新建终端

操作：Ghostty交互；终端、文件、命令、状态统一通过窗口顶部标签选择/关闭/排序；四向拆分、跨组移动、合并；空组自动收起；卡片标题拖动聚合，终端标题打开下方文件及右侧 / 下方新终端，连接中即占位，占位卡片连接时按钮为「取消连接」、失败后为「重试连接 / 关闭此标签」；键盘新建终端标签（macOS Cmd+T，Windows / Linux Ctrl+Shift+T），视图菜单「上一个 / 下一个标签」（macOS Cmd+Option+← / →，其他 Ctrl+Shift+Tab / Ctrl+Tab）按顶部顺序循环，只激活不改布局；模态提示或其他窗口获得焦点时不切换

状态：排队、连接中、取消、失败重试、断开、主机指纹变化

边界：分组不是多个独立工具实例；不提供批量广播；终端标题高32，正文左右内边距16、上下2，收紧标题字形到首行命令的视觉空白；分栏内部仅显示当前视图标题和操作，不显示选项卡；顶部标签最宽210，多标签时先按可用宽度均分（最小72，含关闭按钮）再横向滚动，单标签规则不变

源码：internal/desktop/terminal_group_view.go; internal/desktop/terminal_layout.go; internal/desktop/terminal_colors.go; internal/desktop/app.go; internal/desktop/connection_pending.go; internal/desktop/workspace_tabs.go; internal/desktop/workspace_tab_width.go; internal/desktop/workspace_drag.go; internal/desktop/chrome.go

源码：internal/desktop/terminal_group_view.go; internal/desktop/workspace_menu.go; internal/desktop/workspace_tabs.go
