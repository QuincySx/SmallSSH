# 功能进度

本表保留最初提出的范围；未实现的条目不算完成，也没有因本轮做预览而从范围中删除。

| 功能 | 当前状态 |
|---|---|
| 界面缩放 | 「视图」菜单放大 / 缩小 / 实际大小，按固定档位（50%–300%）切换；MyGo 以缩放后的尺寸重新布局与绘制，文字、图标、矢量保持清晰。比例随布局保存（`layout.json` v3），旧版布局读取后默认 100%。macOS 快捷键 Cmd++ / Cmd+- / Cmd+0，Windows / Linux 为 Ctrl+Shift+ 同上，裸 Ctrl 仍归终端 |
| 整窗响应式与宽屏卡片布局 | 主窗口最小宽度降为 560 DIP；卡片按内容密度设置最小可读宽度与列数上限：文件系统最多三列，Docker 清单、Compose 项目及项目内的容器最多两列。列数同时受实际卡片数量限制，单张撑满整行，够放两张最小宽度及间距后才均分两列，不预留整列空位。末行保持列宽，Docker 清单保留虚拟网格。概览仅保留 CPU / 内存 / 网络 / 磁盘四卡及系统摘要，卡片按 180 DIP 最小宽度排列一至四列，底部浅面板切换紧凑密度；资源区右侧预留滚动条空间；窄窗搜索工具栏换行，右侧停靠在空间不足时暂时回到底部，拉宽后恢复保存的右侧选择 |
| Compose 项目视图 | 一张卡代表一个检测到的 Compose 项目，汇总运行状态、CPU、内存并预览容器子状态；点击查看容器，项目菜单提供更新、启动、停止、重启；操作前确认服务器及全部已发现服务，执行前复核容器成员与来源，搜索不改变操作范围。来源不完整禁用更新、部分资源明确标记，原生虚拟网格保留响应式与滚动。无窗口流程及本机真实 Docker 隔离项目检测通过 |
| 服务器状态各区域的布局评估 | 系统 / 硬件、物理 / 虚拟网卡、块设备 I/O、容器信息及端口映射按内容宽度排一至两列，单张撑满；核心仪表按实际核心数排最多四列，文件系统最多三列，Docker / Compose 最多两列。网卡内部按卡片自身宽度切换指标密度；长硬件信息、IPv6 和容器端口映射可换行，日志工具栏窄窗换行。进程 / 服务 / 容器 / 镜像保留可排序表格与横向滚动。主机监听端口独立清单、GPU 数据尚未实现 |
| macOS / Windows / Linux 原生桌面 | 三平台可构建；macOS 已实际操作验收；另两平台待实机 |
| 同一共享代理供桌面和 CLI 使用 | 已实现并贯通测试 |
| 加密保存连接、密码、私钥和私钥口令 | 已实现 |
| 密码、私钥、指定 agent 身份登录 | 已实现并使用本地真实 SSH 协议测试 |
| 新建 / 编辑连接、凭据保留或更换、取消与失败恢复 | 统一为居中 Dialog，保留工作区、固定操作按钮、端口和分组直接可见；首次身份核对在同一弹窗内完成。密码 / 普通及加密私钥的无窗口表单 → 加密保存 → 重开库 → SSH 登录 / Ghostty 回显测试通过；系统文件选择器结果边界使用替身，未重新做原生弹窗操作验收 |
| 强制主机指纹核对 | 已实现；网络探测不会自动信任；变化拒绝登录，提供明确的重新核对入口 |
| 原生多终端、Ghostty 交互、窗口缩放 | 已实现；每次双击新建独立终端、同机多标签、原标签重连；人工终端随关闭 / 锁定结束，外部请求仍有期限；macOS 实测输入与远端回显 |

| AI 请求、桌面弹窗、终端批准、拒绝、撤销、期限 | 已实现；两种批准入口均实测 |
| 客户端长会话与 AI 子授权 | 已接入现有本地密码库：所有者批准指定服务器、只读 / 完整范围及期限；客户端公钥与配对码绑定，30 秒一次性挑战、最多 5 分钟子票据、父授权绝对 / 闲置期限、级联撤销；CLI、传输和授权中心贯通隔离测试。支持客户端环境复用会话，范围内不逐项询问；自然过期后实际操作自动申请原范围续期，并发共用一次审批，批准后继续，拒绝 / 撤销不重试；单次请求静默进入授权中心，会话申请合并提醒。1Password / Bitwarden 后端及启动按需解锁尚未接入（历史目录权限问题已解除，功能仍待实现）；见 [会话与子授权](DELEGATION.md) |
