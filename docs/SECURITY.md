# 安全与边界

SmallSSH 在本机后台 `smallsshd` 内集中核验目标、凭据、权限和操作。桌面解锁、应用签名身份、服务器信任和具体操作批准是各自独立的步骤。

## 保存、连接与本机信任

- 保存连接只做本机校验和加密落盘。双击、Enter 或明确选择连接线路时才联网。首次连接按本次线路核对指纹，目标认证发生在信任后。更换地址、端口或主机指纹时重新核对。
- 密码、私钥、代理凭据和策略保存在加密保险库中。主密码或系统验证建立所有者管理会话，桌面和 CLI 通过限时管理证明调用后台。
- 快速解锁材料只留在本机后台内存，绑定桌面程序身份，最长 48 小时。后台重启或材料失效后需再次输入主密码。
- 可信解锁建立稳定的代理公钥配对。CLI 的 TLS 1.3 连接校验该配对或显式配置的公钥摘要。修复配对需要可信桌面确认。
- macOS 核验内核 audit token 和动态签名身份。Linux 核验 socket 的 peer pidfd、进程启动标识及映像。Windows 核验命名管道对端进程实例和映像。不可核验的受托身份会被拒绝。应用 ID 和自报名称用于展示。

## 服务器操作与密钥使用授权

| 授权 | 范围 |
| --- | --- |
| 服务器操作 | 绑定申请端进程、服务器、权限范围和期限。可以逐项审批或批准同一个会话。 |
| SSH 密钥使用 | 允许签名，私钥留在签名组件内。macOS 的限时许可按整把密钥生效，撤销影响后续签名。 |

macOS 系统验证、批准与通知属于密钥使用流程。签名成功后可通过系统通知查看来源和密钥，并经验证开启限时许可。密钥重新进入锁定后须重新授权。当前的签名事件和授权变更可在审计查看。

标准 SSH Agent 只看到签名请求。外部 SSH 登录后的命令由远端账户权限控制。SmallSSH 的 CLI / SDK 分级审批覆盖经过本机后台的操作。

## 受托会话

| 权限 | 审批规则 |
| --- | --- |
| `guarded` | 默认。已识别的低风险操作直接执行，中风险及未知命令逐项确认，已识别高风险直接拒绝。 |
| `read` | 限定的读取能力。 |
| `maintenance` | 固定检查、指定来源备份下载 / 续传、APT 升级预览。 |
| `full` | 显式批准较宽范围，由服务器策略和路径规则继续约束。 |

父授权最长 24 小时，子操作许可最长 5 分钟。每个子许可绑定实际进程、父会话、服务器及指纹、具体操作和操作连接。票据可消费一次。关闭控制连接、撤销、锁定或身份变化会结束作用范围内的访问。符合条件的自然过期会话可在原活连接上请求新一代批准，维护准备到期即结束。

所有者可在受控会话审批、当前授权或关联审计详情中调整中风险文件操作确认。关掉后，范围内指定的普通 SFTP 文件变更可直接执行。重新开启会撤销尚未使用的自动许可，已经开始的操作继续，原待确认请求仍需批准。调整绑定当前授权世代，按次记录前后状态，不延长原期限。续期时默认开启确认。

会话在内存中持有客户端密钥和控制连接。`readRoot/writeRoot` 将结构化文件操作限定在明确路径内，省略相应一侧表示不开放该方向。使用方法见 [CLI 与 SDK](CLI.md#连续客户端会话)。

## 服务器策略与执行边界

- 代理配置只导入支持的出站节点和参数。导入时保留 TLS 身份校验或要求有效公钥 pin。密码、PSK 等秘密写入加密保险库。线路失败时会报错，直连需显式选择。
- 每台服务器可禁用 AI / CLI。后台在探测、连接和凭据使用前核对策略。策略更改可使已有授权失效。
- 结构化文件操作先检查规范路径、保护范围及符号链接。保护模式下，写入现有远端分片及部分属性变更受限。SFTP 的路径检查无法锁住其他远端进程或证明所有文件系统别名。
- `exec` 的命令护栏只能覆盖已识别的危险模式。任意脚本或解释器不能靠字符串检查证明只访问指定目录。严格约束应使用限定的操作类型，并结合服务器账户权限。
- 上传绑定内容指纹，覆盖保存核对旧内容并保留副本。SFTP 的最后一次内容检查与提交间仍有外部写入竞态。传输队列记录进度和摘要。续传重新核对源内容及前缀。
- 锁定、撤销或断线可停止受控访问。已交给远端服务管理器的任务可能继续，需要查询远端实际结果。程序不会自动重放已开始的写操作。

## 审计与保留

本机私有 `audit.jsonl` 记录请求、来源、授权变更、操作目标和结果。可识别的进程实例、映像摘要、命令及路径摘录供核对，自报标签单独标记。日志不会保存凭据字段、票据、SSH 签名原文或命令输出。命令和路径摘录本身可能包含输入过的敏感信息。

审计按文件轮转保留，使用链校验及保险库锚点检测异常。所有者可以在授权中心按类型、应用、结果、时间及内容筛选并导出 JSONL / CSV。JSONL 保留源记录与链标记。筛选结果是原记录的子集。审计规则修改包括中风险开关切换前后的状态，已有记录保留当时的勾选。

本机策略依赖操作系统进程隔离。拥有同一账户任意调试、注入或内存读取能力的进程可能突破应用层约束。公开发布需要独立的签名、平台和真实环境验收，见 [验收记录](VERIFICATION.md)。
